# reports/

**Frozen historical archive.** Every directory here is a point-in-time artifact from the
date in its name. None of it is maintained, and several contain infrastructure facts
(hosts, paths, build machines) that were true then and are not now.

**The current status of record is [../PROGRAM_STATUS.md](../PROGRAM_STATUS.md)**, itself a
2026-07-17 snapshot — and the authoritative record of withdrawn claims is the per-module
`evidence/phase0/kpis/RETRACTION-INDEX.md` files. Prefer both over anything in this directory.

Build scripts inside these directories reference paths outside the repository and are not
expected to run.

Use `ls reports/` for the list; each directory is named for its date.
