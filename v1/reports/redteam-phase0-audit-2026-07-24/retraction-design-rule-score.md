# Retraction: amphora-design-rule-score "R² +0.856" scratch-hardness result

**Date:** 2026-07-24
**Status:** RETRACTED — the claim is an evaluation artifact, not a finding.
**Action required:** remove from the founder report; do not cite in any form.

## What was claimed

The 2026-07-24 audit (`README.md`, §6 item 2) and prior portfolio material
described a HistGradientBoosting model predicting Erichsen scratch hardness
(`Kratzhärte`, N) on the PURformance 2K-PU dataset at **R² +0.856**, against a
"physical baseline" of **+0.016**, and called it "the strongest positive ML
result in the portfolio". That characterisation was wrong. It was written
without re-executing the evaluation or inspecting the fold composition.

## Why it fails

**1. The folds are nested, not disjoint.** The protocol is labelled
`leave_one_iteration_out_LOIO` over three folds built from
`Experiment/iteration_{1,2,3}_doe_actual.xlsx`. Those three files are
*cumulative*: iteration_1 ⊂ iteration_2 ⊂ iteration_3 (17 → 27 → 42 rows).
The advertised "86 formulations" are **42 unique formulations counted 86
times**. Row-level audit of what appears in training while being scored as
test:

| held-out fold | n_test | exact (X,y) duplicate in train | identical y in train |
|---|---|---|---|
| iteration_1 | 17 | 1 (6%) | 17/17 (100%) |
| iteration_2 | 27 | 27/27 (100%) | 27/27 (100%) |
| iteration_3 | 42 | 27/42 (64%) | 27/42 (64%) |
| **total** | **86** | **55/86 (64%)** | **71/86 (83%)** |

The module's own conformal receipt corroborates this: fold-2 MAE = 0.183 N
(100% leaked) versus fold-3 MAE = 0.860 N (64% leaked) — a 4.7× error
gradient tracking the leakage fraction. An MAE of 0.183 N on a target with
σ = 3.05 N, from four DoE setpoints, is not physically credible.

**2. The result is inside its own null distribution.** The receipt's hostile
null (`B6_hostile_null_HistGBM_y_shuffled`, R² −0.417) shuffles only
`y_train`, which destroys the very label-matching between duplicated train and
test rows that the model exploits — it is structurally incapable of detecting
this failure. Permuting labels at the *unique-formulation* level and then
running the published protocol gives R² = [0.859, 0.708, 0.719, 0.473, 0.585,
0.680], **mean +0.671 on random labels**. The claimed +0.856 is not
distinguishable from noise generated by the protocol itself.

**3. The baseline was the weakest of six available.** The same receipt
reports: constant −0.012; Vernetzung-only ("physical") +0.016; OLS all four
features +0.334; ridge +0.335; **ridge with interactions and quadratics
+0.468**; HistGBM +0.856. Quoting +0.016 rather than +0.468 inflates the
stated gap from 0.388 to 0.840 — a 2.2× exaggeration. The Vernetzung-only
baseline cannot explain the other three factors' variance *by construction of
the DoE*, so it measures the experiment design, not coating physics.

**4. It violates the project's own frozen protocol.**
`config/program/design-rule-split.v1.json` (frozen 2026-07-18) requires
`overlap_policy: NO_FILE_OR_REPLICATE_MAY_APPEAR_IN_MULTIPLE_SPLITS`
(violated), assigns splits by per-iteration *directory* rather than the
cumulative root files that were actually read, seals
`Experiment/Random_test/` as a held-out test set (never used), and
pre-registers `STANDARDIZED_RIDGE` as the fixed estimator — not HistGBM.
Iteration_4 (13 formulations) and the sealed random test (10) were left
untouched, so 23 of the 65 published formulations were never evaluated.

**5. No confidence interval exists.** No CI, standard error, or bootstrap on
R² appears in any of the four receipts. With 42 unique formulations in 3
nested folds the effective number of independent units is ~1–3, and a cluster
bootstrap is not estimable.

**6. The module already contains the refutation.** In the same directory,
signed by the same key, `purformance_multi_target_coating_model_receipt.v1.json`
evaluates *the same target* on the correct 65-formulation master file
(`Evaluation/PURformance-Dataset.xlsx`) across its 6 disjoint blocks:

```
gbm      R² = −0.2586     gbm_beats_constant_lobo : false
ridge    R² = +0.0505     gbm_beats_ridge_lobo    : false
constant R² = −0.0574     random 5-fold gbm R²    = −0.2028
```

Independent re-runs agree with −0.259, not +0.856: dedup to 42 unique
formulations with LOO-CV gives HistGBM −0.595 (ridge +0.106, constant −0.049);
a prospective train-on-iteration-2 → test-on-new-iteration-3-rows split gives
−2.473. **Every leakage-free evaluation places the model at or below a
constant predictor.**

## The actual finding

On this dataset, four normalised DoE setpoints do not predict scratch
hardness, and the gradient-boosted model is the worst of the candidates
tested. Film thickness — a first-order driver that the source paper treats as
a confounder — is excluded from the feature set entirely.

## What is genuinely good here

Rights and provenance are clean and are the strongest part of the artifact:
Zenodo 13742098 (Cordts et al. 2024, *Chem. Mater.*), CC-BY-4.0 with vendored
license text and HTTP headers, a signed rights receipt with
`rights_class: DERIVATIVE_ALLOWED` and `authority_ceiling: AUDIT_ONLY`. The
module's own `ip/claim-contract.v1.json` sets `no_superiority_claim: true` and
`directional_hypothesis_only: true` — the portfolio framing violated the
module's own contract, which the contract itself would have caught.

## What a defensible re-run requires

1. Read `Evaluation/PURformance-Dataset.xlsx` (65 unique formulations, 6
   disjoint sheets); never the cumulative `iteration_N_doe_actual.xlsx` files.
2. Compute and record a row-hash disjointness manifest in
   `split-manifest.v1.json` — the existing
   `source_family_scaffold_time_lot_leakage_forbidden` flag is asserted, never
   verified. Require zero (X,y) and zero y-value intersection across folds.
3. Honour the frozen split: report `Experiment/Random_test/` once, at the end;
   include Iteration_4.
4. Report the pre-registered `STANDARDIZED_RIDGE` as the primary result;
   HistGBM only as a logged exploratory deviation.
5. Replace the null: permute labels at unique-formulation level and require
   null R² ≤ 0.
6. Report a block bootstrap CI over the 6 blocks and state effective n.
7. Headline against ridge-with-interactions (+0.468), not Vernetzung-only.
8. Include film thickness as a covariate or justify its exclusion.
9. Commit the generator script — no script in the repo produces these
   receipts, so the numbers are signed but not reproducible.
10. `src/` and `tests/` are empty directories; nothing in the repo consumes
    this model. Build the module or drop the claim.

## Process lesson

This number survived because signing, rights checking, and receipt generation
all succeeded — the trust kernel verified everything *except whether the
evaluation measured what it claimed*. Fold composition was never audited at
row level. The same audit applied to the solvency BigSolDB benchmark
(leave-solute-out, grouped by canonical SMILES) found 0 residual duplicate
rows and 3.6% of rows with a Tanimoto-1.0 solute twin, versus 64% here; that
figure is now reported in that benchmark's receipt rather than assumed.
