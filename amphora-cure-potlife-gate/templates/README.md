# Pot-life operator templates

These files are intentionally incomplete operator aids, not evidence. Copy a
template to a working location and replace every blank, zero, `REPLACE_*`, and
`false` placeholder with measured, hash-bound, identity-bound, or reviewed
values as the contract requires.

Untouched templates must fail `pot-life preflight`. A passing preflight checks
contract shape and integrity only; it does not create an artifact, identity,
receipt, scientific promotion, or authority.
