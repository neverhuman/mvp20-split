# Artifact ancestry footprint contract

POP-01.08 owns this additive read-only response. Data returns a scoped root and
distinct root-plus-ancestor count, catalog content-byte sum and existing
derived-closure membership digest. Counts include both conversion and derivation
ancestry. No member list, payload, rights grant, retention or execution authority.
The observation describes one catalog cut; later conversion registration can change
it. Consumers must re-assess changed observations. Existing owner completion and
protection checks remain authoritative. No persistence or network code belongs here.
