# Typed Artifact binding fixtures

Owner: [campaign contracts](../../campaigns/README.md); implementation: [compiler](../../../services/campaign_runtime/src/amphora_campaign_runtime/compiler/README.md); plan: [BP-04.04A](../../../docs/Build%20Plans/BP-04/BP-04.04A%20Typed%20artifact%20and%20collection%20bindings.md).

`binding_cases.json` is independently authored wire-v4 input, with scalar/collection projection, reference-list projection, inline member publication and finite object materialization. Invalid cases reject unknown modes, arbitrary code, oversized resource limits and accidental use of an old profile. `schemas.json` pins exact local data schemas. `predecessor_schema_pins.json` freezes all 134 previously published schemas. `binding_primitives.json` is the public builtin primitive catalog; these are Runtime-owned operators, not fake scientific tool releases or registry eligibility decisions.

Projection consumes one scoped JSON Artifact plus a finite path. `values` exposes typed scalars or a bounded homogeneous scalar collection. `references` interprets an explicit ArtifactRef array and requires independent owner verification/protection before references become graph values. `items` validates each inline array element against the pinned member schema and publishes member Artifacts before committing ordered membership. Empty arrays are legitimate; values that merely resemble references remain data in `items` mode. Projected collections do not invent missing members.

Materialization has a bounded, uniquely named field list; field order is nonsemantic, collection member order is semantic. Each field chooses `inline` values or `references` explicitly. Inline Artifact values require verified bytes/schema; reference mode emits verified pins. Missing collection slots retain their member/reason record and must be accepted by the declared output schema; they are never silently filtered. The compiler validates source availability, modes, types/units, named fields and declared bounds. Runtime must validate actual assembled content against the entire output schema before publication/acceptance; compilation does not prove every possible payload will satisfy that schema.

Limits bound member count, Artifact operations, total bytes and elapsed time. Conversion is a resumable Runtime operation with public Artifact I/O outside SQL, stable identities, cancellation/deadline revalidation and explicit protection. B1 supplies the wire/compiler boundary. Runtime 0.9.0 implements the durable B2 path with explicit binding peer configuration; default admission still returns `graph_binding_profile_not_enabled`. Published v1-v3 execution meanings remain unchanged; configured hosting exposes graph-page v3.
