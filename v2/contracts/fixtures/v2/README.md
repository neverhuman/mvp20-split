# Executable Wire Examples

These manually specified cases exercise explicit bindings, branch/all-join, bounded scatter, loop state/feedback, occurrence identity and strict invalid shapes. Tool/schema identity is taken from preserved synthetic image/registry evidence. The plan and lock examples are wire fixtures, not proof that a compiler produced or accepted them. Runtime semantic compiler tests own cycles, routes, types, units, normalization and hash validation.

Wire-v1 fixtures remain separate and are not converted implicitly. JSON Schema and Pydantic validate every case in the owning campaign suite.
