# Research Contracts

Version0.8.0 adds SyntheticLabReport, LabReturnProfile and LabReportResolution (six additive schemas;330 predecessors unchanged). lab_reports.py owns the explicitly synthetic producer format and its self-contained payload-schema helper/digest. Producer rows omit their source Artifact to avoid a circular hash; Research attaches the authenticated source after reading Data. Profiles pin exact stored experiments, adapter versions and publishers. Rows preserve original values, binding claims and quality/control flags; empty returns are explicit, with a64-row ceiling.

A reconciliation document distinguishes expected-return coverage from unavailable values, mismatched rows and scientific quality. Complete coverage never asserts scientific acceptance. Matching does not erase failed controls or make optional weaknesses mandatory gates. Producer payloads cannot supply owner acceptance verdicts. Source/issuer/method/rights validation and semantic reconstruction are Research behavior, not DTO authority. New intake decision storage and public submission APIs remain B1.07/B1.08. Compatibility-only peer pins are Evidence0.5.7, Knowledge contracts0.7.2/owner0.15.2 and Data0.11.7.


Version0.7.0 adds MaterialStateRevision, ExperimentDefinition, ObservationRevision, SynthesisProfile/Assessment and EligibilityProfile/Assessment. Seven new roots publish14 schemas while preserving all316 predecessors. CandidateRevisionRef, MaterialStateRevisionRef and SampleIdentity remain unchanged. Examples are synthetic shape fixtures with placeholder artifact digests, not retrievable lab evidence.

Focused modules measurements.py/materials.py/experiments.py/observations.py/synthesis.py/eligibility.py own their transport subsets. Exact numeric values use bounded decimal strings; discriminated numeric/categorical/censored/missing/series variants preserve original meaning. Nullable fields remain explicit. Unit/decimal lexical patterns and collection limits are transport checks; exponent/precision bounds, interval coherence, scientific identity/context, predecessor chains, step dependencies and evidence sufficiency are enforced by Research domain reconstruction. JSON Schema success is not domain acceptance. Measurement regex patterns use an explicit end-of-input assertion so trailing newlines cannot differ between Python and JSON Schema validation.

Profiles are trusted configuration documents, not a permission to accept caller-supplied verdicts. Profile/assessment authority is fixed synthetic; evidence origins may retain rejected scientific claims without promoting them. Full policy configuration, exact context, alternatives, blockers/gaps, criterion reviews and follow-up focus are retained. The owner creates assessment output through domain policies. These payload documents do not yet define persistent decision identities, public submit endpoints, receipt publication or Runtime authority; later store/API milestones own their envelopes and source-resolution rules.

Research explicitly maps DTOs to/from private domain objects. Mapping does not authenticate an Artifact or execute a physical experiment. Assessment output is projected from owner policy; no mapper turns arbitrary output verdicts into trusted input. New document schemas leave existing assessment/publication/correction protocols untouched. Exact dependency compatibility patches coordinate Evidence0.5.6, Knowledge contracts0.7.1, Knowledge0.15.1 and Data0.11.6; peer implementation code remains unchanged.


Version0.6.0 adds CorrectAssessmentReceipt and SelectAssessmentReceipt: reference-only owner correction and explicit future-campaign selection. Returns shared ReceiptCorrectionView from graph-runtime0.13.0, including the exact revision reference for later selection or expected-head comparison. - Package: `amphora-contracts-research` 0.8.0, wire1; identity declarations and synthetic assessment shapes.
- Design: [Candidates](../../docs/Architecture/Research/Candidates.md), [experiments](../../docs/Architecture/Research/Experiments.md).

Public imports use `amphora_contracts_research`; public Core, Artifacts and Graph Runtime contracts plus Pydantic dependencies. DTOs are immutable, strict, bounded and extra-forbidden. No service code, storage, scientific evaluation or permission is provided.

CandidateRevision identifies an intended design with its exact representation artifact. SampleIdentity identifies a physical sample, its exact candidate revision, optional exact material-state revision, and identity-evidence artifact. Missing material state stays null; nominal equality never invents a preparation history or specimen. MaterialStateRevisionRef remains unchanged; the additive MaterialStateRevision document now preserves preparation and feature evidence.

ResearchQuestion pins objective, scoped applicability artifact and predeclared answer criteria. EvidenceNeed pins an exact question revision, selected criterion IDs, required method schema and scoped context artifact. These records describe required evidence; they neither assert that a question is answered nor publish Knowledge claims. Text/criterion descriptions are data, never executable instructions.

The Research owner verifies matching scope, duplicate/unknown criteria, exact predecessor chains and referenced candidate/question existence. Artifact availability/current rights require public Data checks. JSON Schema shape validity cannot authorize evidence use. A future owner store must enforce immutable identity/revision, compare-and-swap heads and replay; this package alone has no durability. Corrections use a new revision rather than silently changing an existing record.

Tests in `tests/` exercise Python/JSON Schema parity and distinct scientific identities. The schema exporter publishes both modes. Replacement preserves public roots and shape fixtures; service behavior is specified separately in the source-adjacent Research README.

Version0.3.0 adds EvidenceAssessmentProfile/Request/Status and EvidenceAssessment roots. Profiles are trusted configuration, with exact question/need declarations, subject, criterion target digests and allowed publisher/issuer identities. Requests contain only profile/question references, answer artifact references and receipt artifact references; no verdict, trust or scientific-acceptance input is allowed. Pending/failed/assessed status is explicit. An assessed result is a Research decision record, not an artifact-publication receipt or Runtime acceptance. Its authority is synthetic and scientifically_established is strictly JSON false (numeric0 is rejected too).

Profile fingerprints are SHA-256 of sorted-key compact UTF-8 JSON of the full wire document, no trailing newline; array order is significant. Each target_sha256 pins a Knowledge GroundLiteral using the same JSON encoding, resolved by the Research service without introducing a Knowledge-contract dependency here. Shape validation alone cannot establish target correspondence, trusted publishers or immutable store history. Examples in examples/ are synthetic shape fixtures; their placeholder artifact digests are not retrievable scientific data.

The owner validates complete target coverage, unique trust entries, exact scoped request/profile bindings and resolved-reference equality before mapping domain decisions to wire records. Profile/wire schemas do not execute those rules. Existing0.2.0 schema bytes are preserved; downstream exact dependency pins were coordinated in compatibility patch releases. No assessment HTTP route, authentication adapter or persistence is supplied by this package.

Version0.5.0 adds SyntheticEvidenceRecord and self-contained payload-schema helpers. The payload names exact need/criterion/answer subject, method/context, evidence category, issuer, purpose and disposition, with literal synthetic authority. It is a producer claim, not a Runtime DomainReceipt or proof of publisher identity. Research verifies Data's derived-publication origin actor against trusted configuration and the declared issuer before using it. Publication must declare the answer/context inputs and use a transformation descriptor whose id/version/digest equals the payload method SchemaRef. Unknown or wrong-category evidence cannot promote scientific acceptance. All294 predecessor schema bytes remain unchanged; two export schemas are additive. The helper payload schema omits the exporter URN/base and has its own digest.

Version0.2.0 adds ResolveIdentity and IdentityResolution for authenticated scoped reads. authority is the literal identity_only; matching proves exact owner record correspondence, not artifact rights or scientific eligibility. These additive roots leave prior identity/question schemas unchanged.

B1.10 adds reference-only AssessmentPublicationRequest and typed pending/failed/published AssessmentPublicationStatus. Published output includes the public DerivationReceipt and DomainReceipt; their presence is not Runtime acceptance. Failed publication explicitly preserves possible external effects. Four additive schemas preserve prior public schema bytes. Dependency direction remains acyclic: Research contracts consume Graph Runtime/Artifacts, never Knowledge contracts; Knowledge can continue consuming Research.
