# Fitness projection transport

- Owner: BP-08.03/B2.02b; version0.1.0, verified 2026-10-06 14:05:50.
- Design: [Representation and fitness](../../docs/Architecture/Campaigns/Representation_Fitness.md).

Profiles transport a scoped synthetic evaluation policy, exact observation-use policy and explicit synthesis requirement. Requests contain only owner/Artifact/profile references and a bounded operation identity. Projections retain complete committed owner evidence, configuration, original request, declared identity and per-axis availability/provenance. Measurement uncertainty remains in the original and normalized observation reviews. `synthetic_owner_projection` and `reuse_authority=none` prevent the transport from claiming scientific validity or cache permission.

DTOs validate closed shapes only. Research owns policy fingerprints, scope/actor resolution, current Artifact access, fitness assembly, exact retry and immutable storage. These records neither execute tools nor authenticate canonicalization/evaluator claims. Existing public contracts remain unchanged. Module tests own wire shape and schema parity; Research tests own behavior, SQL and API acceptance. Replacements must preserve original bytes and attribution or explicitly version the boundary.

Verification: three wire/parity cases plus full177-check owner/publication/boundary run. Twelve new schemas preserve all590predecessors. DTO coverage measures shape only; no scientific authority or actual peer evidence follows from it.
