# Representation contracts

Version 0.3.0; wire version 1. [Architecture](../../docs/Architecture/Data/Representations.md), [owning plan](../../docs/Build%20Plans/BP-06/Completed/BP-06.05%20Representation%20reuse%20and%20retrieval.md).

This independently packaged public boundary serializes complete encoding profiles, scoped profile references, exact source-span encoding requests, retained vector documents, attributable source bindings and pending/published status. It depends only on Pydantic and public Core/Evidence contracts. Import the package root; private source modules are not a consumer API.

Profiles expose every result-affecting encoder/input/pipeline/space choice plus applicability, limitations and determinism. Registry identity adds scope, id/version and a Data-verified complete-profile digest. Equal dimensions do not establish compatibility. Source requests cannot supply vectors, cache-hit claims, source rights or scientific authority.

Vector Artifact documents retain profile/input/context identity and bounded lowercase hexadecimal binary32 payloads. Schema validation checks shape only: Data validates exact byte length, finiteness, canonical zero, digest, registry scope/profile and context consistency. `representation_vector_schema()` returns the exact generated validation-schema digest used by Artifact publication. Vector payload digest alone is not a full representation identity.

Bindings retain their own scoped identity, profile, source span and derived Artifact. Independent sources never gain rights from shared content hashes. The discriminated status outcome prevents pending results from exposing a binding and requires a binding for published results. Data must still verify actor, source/span, all cross-field references, attribution and publication before returning that state.

There is no encoder, database, API, cache, permission policy or backend here. Schemas grant no scientific validity, executable authority or provenance trust. Initial Data support is a bounded synthetic fixture; contextual/general scientific profiles are descriptors, not evidence of supported providers. Generation DTOs are implemented; retrieval query/result DTOs are implemented; runtime authority remains Data-owned.

`examples/` contains synthetic wire fixtures, not retained owner records. The example binding digest is a placeholder for later owner verification. Profile/runtime references are fixed example identities rather than a claim about every consumer's machine. `tests/` checks examples against both published schema modes, rejects malformed or authority-injecting inputs and verifies exact schema identity. Run `dev/run_tests.py --module representations`; Data's mapping tests are separately owned under `--module data-artifacts --area representations`.

Compatibility is additive: seven new roots publish fourteen input/output schemas under `representations.*`; the preceding 406 schema files must remain byte-identical. No existing public schema, command bytes or Data migration changes. A replacement must preserve wire names, bounds, discriminated outcomes, schema identities and owner rejection of semantically inconsistent documents.

B2.01b adds five roots (ten schemas): `IndexGenerationRef`, `BuildIndexGeneration`, `IndexManifest`, `IndexGeneration`, `IndexGenerationStatus`. Requests specify corpus/generation, exact profile, 1..256 ordered binding references and explicit expected prior head (null for the initial generation). They cannot supply an actor, namespace, backend configuration, vectors or verification success. Data selects authenticated actor and trusted backend and resolves exact retained bindings.

A manifest projects complete bindings and its exact watermark. A generation projects its immutable identity, actor, manifest, expected head and backend descriptor. Status is a projection of the six named lifecycle phases; a shaped `published` or `verified` value is never an admission command or proof. Data recomputes profile/manifest/generation identity and separately enforces retained authority. Examples contain placeholder digests; they establish wire shape only. All 420 preceding schema bytes are preserved; the publication now has 430 schemas. No historical vector schema identity changes.

B2.03a adds `RetrievalPolicy`, `RetrieveRepresentations`, `RetrievalMatch`, `RetrievalRecord` (eight schemas;438 total,430 preceding files unchanged). Requests pin exact generation/query binding and policy; no actor/vector/namespace/rights assertion is accepted. Policy explicitly names exact Dot, stable ordering, top-k and optional binding set, with quality_filter=none. No review-state predicates are supported without an owner projection. Results retain full selected source/vector provenance, query/result digests and finite scores, with no unauthorized omission counts or confidence claim. Data recomputes these identities and enforces current rights before exposure; examples have placeholder digests and establish shape only.

Existing wire fingerprints use SHA256 over sorted-key compact UTF-8 JSON, ensure_ascii=False, allow_nan=False and no trailing newline. Binding projection hashes `{format:"data.representation-binding.v1",binding_id,scope,profile,source,vector}` (complete public records, at most64KiB). Query identity hashes `{format:"data.retrieval-query.v1",retrieval_id,actor_id,generation,query,policy}`, where generation is the complete reference, query is the complete binding, and policy normalizes its optional allow-set by `(binding_id,sha256)` while preserving null versus empty. Result identity hashes `{format:"data.retrieval-result.v1",query_sha256,matches}`, where each match is `{binding:<binding reference>,score:<finite float with signed zero normalized>}` in score-descending/binding-ascending order. Query/result encodings are bounded4MiB. Consumers must separately verify full binding projection hashes; result digest alone covers references, not their expanded provenance. This documents existing protocols without changing schemas or granting access, complete-generation membership or scientific authority.
