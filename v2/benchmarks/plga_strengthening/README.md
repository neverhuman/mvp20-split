# PLGA stage 2: post-pilot internal validation

This isolated user-authorized campaign extends the immutable prefix pilot. It does not resume platform development or change the original results. All Bao curves have already been examined; nested folds do not create a fresh external test.

The six frozen arms separate ordinary kinetic summaries, minimum-error selection and Pareto selection from a matched candidate pool and fit budget. All three selector arms add the same ten prefix-only KP/Weibull parameter/diagnostic columns and three forecast summaries. A combined arm tests incremental Pareto information; a residual arm uses exactly those combined features and learns a correction around a first-order anchor. Both RF and LightGBM use four fixed configurations, three inner joint-component folds, and five outer joint-component folds. Every arm and all planned contrasts are retained. No search follows the outer scores.

`campaign.py prepare --artifacts DIR` verifies the pilot data hashes, constructs component-disjoint nested splits, records candidate receipts/invariance checks, and hashes source/protocol before scoring. `campaign.py run --artifacts DIR --learner rf|lightgbm --run main|replay` fits one single-thread learner matrix. `campaign.py summarize --artifacts DIR` verifies exact fresh-process replay and produces all-arm results and component-bootstrap contrasts. `launch.py` bounds concurrency, affinity, nice priority, address space, CPU and wall time. Data/results are outside the worktree; existing read-only pilot data are linked, never modified. No models are pickled or loaded.

The copied original Pareto ranking module retains its source/proprietary license; Bao data retain CC BY 4.0 attribution. The benchmark invokes no services, credentials, provider APIs, production tasks or fleet automation. Software execution and retrospective prediction do not establish mechanistic or clinical validity. The small three-record prefix often has only two positive times; two-parameter transformed kinetics are just identified, with declared bounds/fallbacks and no mechanistic interpretation.

Exit gate: complete frozen matrix, all splits free of drug/DOI component overlap, all prefix-only invariance checks passing, independent metric/contrast arithmetic audit and full fresh-process exact replay; report negative and uncertain findings. Preserve the pilot worktree/commit, and return to the existing platform build queue only on separate authorization. This source-adjacent contract is the bounded architecture/drift record; no platform boundary changed.
