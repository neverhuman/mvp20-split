SupervisionResponseBinding revalidates the original request against its owned footprint, then binds response ID/reference/full request hash and the original Planning engagement/request/physical attempt. Attempt ordinal must fit the original limit. Reported usage must contain all counts; unknown usage remains unknown. It does not establish actual stored accounting or available spending authority.

Capture bytes must match observation length/hash and Artifact scope/length/hash. A successful proposed/abstained record requires complete nonempty bytes, a capture Artifact and typed proposal; empty/partial failed or unknown diagnostics remain distinct without fabricated proposals. Callers obtain bytes through Data processing authorization outside acceptance SQL. A reference or matching digest alone is not that permission.

The reviewed campaign profile is independently reconstructed from raw JSON: duplicate/nonfinite/malformed data rejects; canonical payload/hash/action/rationale, declaration digest and all scoped references must match. Candidate/action consistency, original adjustment cut and duplicate input changes are checked. Actual tool/adjustment/evidence policy, stored target state, current rights, deadline, aggregate budget and conditional effects remain B2. Structural compatibility does not establish scientific meaning or an accepted decision.

SupervisionReceiptObservation revalidates the exact public command and full receipt identity/request digest. First authenticated owner receipt supplies an operation ID; subsequent receipts must preserve it. Terminal receipts cannot change. Recorded request/response/cancellation commits bind the exact immutable object ID, revision1 and complete payload digest; original readback is required before status becomes recorded. Until then status is awaiting_readback. A later identical receipt retains and revalidates previously verified readback even when no new read is supplied; malformed prior records cannot manufacture that state. Late response recording is not decision acceptance. Public decision readback is a separate owner-produced record.

No SQL, HTTP, provider invocation, live source grant or execution acceptance is owned here. Direct dataclass construction/readback is not proof of fresh policy.
