# Agent Planning service boundary

Version0.8.0, BP-07.02/B1.01. This isolated owner implements pure context/request validation, physical-attempt binding and a deterministic adversarial provider/capture boundary. It now has a private PostgreSQL request/attempt/observation journal; no server, live provider, output publication, live transport or Runtime acceptance implementation yet. [Design](../../docs/Architecture/Agents/Planning.md) describes the larger target; [build plan](../../docs/Build%20Plans/BP-07/Completed/BP-07.01%20Model%20and%20engagement%20contracts.md) owns current progress.

Public dependencies are planning/core contracts; SQLAlchemy/psycopg/Alembic are private persistence dependencies. Private modules group behavior with its data; transport DTOs do not own policy. Context owns scoped immutable input snapshots. Providers owns bounded deterministic call parsing; persistence owns immutable request/attempt/observation history. Runtime alone accepts execution decisions; Knowledge and Research retain domain authority. No peer private imports, shared ORM or peer-table reads.

The budget module validates owner-configured ceilings and computes pure reservation demands; persistence now atomically reserves those demands with attempt intents. Immutable settlements retain the v1 reservation floor and record truthful overage. Successor attempts require settlement; overage stops new admission. DispatchJournal now issues once-only local tickets and stores deadline recovery/late evidence. PlanningRunner composes these boundaries for bounded deterministic attempts; no remote exactly-once or live cancellation claim.

Tests live under tests/context, tests/providers, tests/persistence tests/budget and tests/orchestration; dev/run_tests.py --module agent-planning --area context --coverage selects them. Replacement must preserve canonical bytes/digests, explicit omission semantics, caller isolation, budget/input bounds and attempt identity. Current fixture records are synthetic and not owner existence, current-rights, tokenizer or model-quality proof. Real model/provider, egress and spend policy require owner selection before calls.

The extraction module adds immutable task/request binding, selected raw UTF-8 source identity, exact byte quotations and reviewed prompt rendering. Public Planning0.3 adds extraction task/draft schemas while retaining every predecessor schema. This milestone does not enable extraction output dispatch: the existing provider profile remains reference-only until B1.02 adds explicit versioned compatibility. Actual source rights, trace publication and semantic proposal policy remain later gates.
