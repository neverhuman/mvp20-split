No private owner imports or SQL are permitted in the controller.

successor changes only the allowed evaluator pin and carries the parent's exact
parameter artifact through a terminal predecessor cut. Comparison/handoff
artifacts preserve the original independent numeric benchmark and label it as
separate engineering evidence; evaluator changes never authorize fitness reuse.

synthetic Registry capacity metadata. It does not prove Linux deployment,
scientific improvement or configured live-model scheduling. V1 owns image/fresh
replacement qualification. Failed attempts retain output/log directories; no
database reset or history deletion is permitted. Credentials stay in process
environments. The driver requires explicit owned PostgreSQL opt-in and the
already migrated fixture (Runtime0028, Planning0020, Data0012). It does not
alter schema history or perform migrations.
