# Reviewed synthetic response fixtures

Profile `planning-reviewed-synthetic-responses.v1` contains54 authored responses for the eighteen unchanged [corpus passages](../corpus/README.md): faithful, deliberately incorrect and abstaining variants. `manifest.json` pins the response file and original corpus manifest; every response also pins its source, prose oracle and native output bytes. The response file is a generated compact data artifact; inspect individual records by `response_id`, not full-file dumps.

The coding agent authored and reviewed the literal responses and correspondence labels against the existing passages/oracles. The scorer did not generate these labels. This is software-fixture review, not independent human/domain-expert review. Faithful examples cover the specified rubric; incorrect examples deliberately express the first forbidden interpretation. Additional tests cover partial output, duplicate meaning matches, forged quote bytes, missing reviews, failure/abstention and hostile schema expansion.

Semantic correspondence is supplied explicitly, using an oracle meaning index for each emitted assertion/question/answer/evidence need/diagnostic/edit. A null match counts as an unmatched prediction. Context preservation and forbidden interpretations have separate reviewed indices. Duplicated meaning matches cannot inflate recall. All emitted units require annotations; entity labels are fixture scaffolding and are not a separate entity-resolution benchmark. The generic fixture predicate `described_as` makes no claim of domain-vocabulary alignment. Native task/prompt/output/quotation/trace checks establish only the boundaries they name; these responses are not submitted to Knowledge. Diagnostic-only outputs explicitly report `no_quoted_candidates` rather than implying that quotations were verified.

Full-source quotations intentionally let correct and incorrect claims share valid citation geometry. Missing opinion-validation methods remain null and inferred answers retain their origin. No true scientific method, assay, external measurement or accepted Knowledge result is invented. Acceptance-authority violations require the public-owner checks in B3.03; a closed profile rejection is not an actual remote owner receipt.

Source text alone enters the source-data compartment. Review labels, oracle prose and split labels never enter provider packets. The two original splits remain intact; both were visible during fixture construction, so no developer-blindness claim is made. Changes to frozen response bytes/labels require a new reviewed fixture profile rather than silently repinning this manifest. Live model scoring and scientific thresholds remain BP-07.05.
