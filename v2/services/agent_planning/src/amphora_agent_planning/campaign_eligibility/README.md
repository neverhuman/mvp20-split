Pure values select reviewed releases and interpret expiring Registry observations; no HTTP, SQL, reservation or execution happens here.

EligibilityConfiguration binds the configured Registry owner/actor, expected Registry policy digest and maximum age1..60 seconds (default5). This policy digest is distinct from the original objective policy Artifact. Configuration contains no credential and does not authenticate its caller. Later durable preparation must pin it before dispatch. EligibilityBatch reconstructs CampaignDecisionReview and BudgetPolicy, permits future drafts only, deduplicates up to64 exact selected locks and derives public ResolveRelease requests from descriptor ports and original declaration context. Unrelated discovered releases are excluded.

EligibilityRequest owns original attempt, named check identity, selected release, configuration and canonical public command. A stable per-tool slot hashes original attempt/owner/actor/check/tool identity; generated rationale is excluded. Same-check replay retains bytes, while a new named check can obtain a fresh observation. The later journal must reject changed configuration or payload under an existing check slot. Direct values do not prove stored origin, current source-processing permission or transport authentication.

EligibilityObservation retains explicit Registry rejection. A positive response must match scope, full lock, descriptor and expected Registry policy, active lifecycle, valid structure, eligible science, available capacity, allowed admission and candidate status. Ancillary deployment/heartbeat replies cannot masquerade as resolve results. Expiry must exceed assessment time; require_fresh requires an aware supplied clock, no future-dated assessment, strict capacity expiry and bounded age. A valid old observation remains historical evidence, not current eligibility.

RegistryReceipt lacks echoed command identity/hash. Keeping it alongside the exact request does not manufacture offline proof of origin; authenticated transport and later owned journaling establish the available provenance. Positive observations reserve no capacity, choose no worker, grant no admission and cannot establish actual scientific validity. Runtime repeats its own admission checks. Weak/missing candidate measurements elsewhere remain visible rather than overriding specific eligibility rules.
