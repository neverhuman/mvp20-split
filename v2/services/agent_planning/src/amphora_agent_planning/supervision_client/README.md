RuntimeClient(actor_id,scope,endpoint,token) accepts only original numeric-v2 runtime.supervision.respond and runtime.supervision.cancel commands matching configured actor/scope. submit(command,window,guard=...) performs exactly one effectful POST. receipt(command,window,previous=...) performs a read-only original-command POST. readback(command,observation,window) fetches the exact response or cancellation. Calls remain separate and explicit; no retry, automatic resubmission, model call, execution decision or accounting refund.

Endpoint is explicit http://127.0.0.1:port with no URL credentials/path/query/fragment. Printable32..512-character bearer stays in memory. No proxies, redirects, credential logging or model-selected URL. JSON duplicates/nonfinite values, compression, wrong media, size/time overflow and invalid public records are rejected. Error bodies are not retained. This Planning-owned transport is independently packaged; no Runtime-private import or peer SQL.

Every write requires a guard before connection and immediately before send, followed by remaining-time verification. A guard is caller-supplied liveness evidence; durable eligibility, lease fencing, intent and provider authority remain with orchestration. No SQL spans transport. Lost response raises ExchangeUnavailable: the original command may have committed. ExchangeDenied, ExchangeAbsent (including receipt-query404), ExchangeConflict and ExchangeInvalid remain distinct. A missing write endpoint is unavailable, not proof of no commit.

A recorded receipt is awaiting_readback until the exact public record is verified; verified history survives another identical receipt without a fresh read. Previous terminal receipts cannot change.
