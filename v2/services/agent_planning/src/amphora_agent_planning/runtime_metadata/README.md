# Runtime reviewed metadata

Owner: Planning, BP-07.03/B1.02b.ii. Public Graph Runtime0.13 and Core0.1 supply DTOs; metadata_reads supplies the closed authenticated GET transport. This module owns campaign-bound compiler metadata observations and selected schema bytes. It has no private Runtime import, compiler, Registry resolver, database, draft writer or activation authority.

`ReviewedUniverse.bind(response, request, expected=None)` validates the original campaign/supervision request, scope, public DTO values before serialization, unique tool bindings/schema references and port names. It reproduces the documented amphora-authoring-universe-v1 hash with compiler profile amphora-deterministic-compiler-v3 and sorted full locks/schema identities. An optional expected pin must match. Arrays may arrive in another order without changing that identity; records remain immutable. The public64-tool/256-schema bounds stay intact.

`RuntimeMetadataReader.universe` returns reviewed compiler_configuration metadata or raises on unavailable/mismatched input. A Registry-discovered descriptor is not necessarily in this reviewed set; this module does not add it. A pin identifies configured materials, not successful compilation, current scientific eligibility, capacity or execution permission. Missing action-specific schemas remain a preparation/compiler concern; discovery alone does not invent them.

`schemas(universe, references, window)` accepts a unique explicit tuple of at most256 schema references from that exact universe. Each reply must match scope, universe and full selected reference. `SchemaObservation` verifies SHA256 of decoded original bytes (<=64KiB), preserving whitespace and Boolean schemas. It parses strict bounded JSON metadata but does not execute validators, resolve references, import handlers or duplicate Runtime compiler policy. Caller-authored schema text remains data. A changed owner universe never silently repins the selection.

The reader preserves independently successful selected schemas alongside reference-bound safe failures. Missing/denied/invalid responses do not erase useful records. Global outage, deadline, call or aggregate-byte exhaustion stops further calls and explicitly marks remaining selected references unavailable. Programming errors propagate. Empty selection performs zero reads. Call/byte deltas remain visible; pass one shared Runtime MetadataWindow across universe/schema reads to bound the entire operation to30s,257 calls and16MiB. No retry or renewal occurs internally.

Tests live under tests/runtime_metadata; the literal fixture was generated by independently installed Runtime0.20.2 ValidationUniverse from synthetic public descriptor vectors and exact object/Boolean schema bytes. Production and isolated Planning tests never import that owner. Fixture compatibility, exact HTTP queries, wrong pins/scopes, strict malformed JSON, partial results and stop conditions are covered. Actual combined-owner HTTP/replacement remains B1.02d; no scientific/source-processing or campaign admission claim follows from metadata checks.
