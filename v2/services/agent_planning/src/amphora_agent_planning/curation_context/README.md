# Campaign curation context

UI-01.08/P2.3b.2 in progress. Architecture: ../../../../../docs/Architecture/Agents/Planning.md.
This module owns original human intent binding to a reviewed campaign request.
CurationIntent reparses immutable command bytes, binds actor/scope, exact curation
identity and command digest as decision_scope, and requires the exact curation
output profile. Human direction and original predecessor/draft/Knowledge/Research
pins enter a required untrusted slice; none become trusted prompt instructions.

from_template uses server-reviewed roots/model/limits and a matching configured
policy ID. Templates cannot hide extra source entries/omissions. Selected Artifacts
become explicit optional source entries; absence remains a visible processing gap.
No Runtime frontier is invented from the simpler predecessor cut. The exact
predecessor stays in original intent until public Runtime verification.

Preparation readback revalidates intent, identity, digest and required inclusion;
original old-profile packets remain unchanged and cannot acquire this new lane.
The value object has no I/O, credentials, provider/Runtime authority or SQL. It does
not prove peer contact, processing rights, scientific quality or active workers.
Remaining: bounded public-owner assembly, exact original graph reads and durable
preparation/job linkage. Tests are module-owned under tests/curation_context.
