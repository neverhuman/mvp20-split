# Named Research view client

Owner: Planning; BP-07.03/B1.02a.ii. Public dependency: Research Views0.1, Research0.14 and Core0.1. This module owns campaign-bound page selection, bounded authenticated reads and identity validation. It has no database, public server, model adapter or scientific acceptance authority.

`ViewSelection.bind(query, request)` accepts only the three public typed queries and campaign_proposal/supervision RequestSnapshot. It revalidates wire values, scope and unique selected observation revisions, retains immutable query bytes and binds a selection hash to the original request. Query digest follows the Research `research.view-query.v1` protocol: ordered exact query including limit, excluding position. Selection digest additionally includes position and campaign request hash. No latest lookup, SQL, model-authored route or arbitrary handler exists.

`ResearchViewReader.read(selection, window)` reads exactly one page. It verifies complete request echo, query hash, nested typed scopes, window cardinality, continuation and selected property order/total. Specimens retain distinct sample identities even for equal candidates; present material must match the sample's selected state/candidate. Series order, repeated coordinates, lexical values, missing material, reported quality and unbound/different-experiment context remain intact. No semantic entailment, laboratory validity or global quality threshold is inferred. Page hash describes observed content, not a source grant or transactional snapshot.

The shared window has20s,32 calls,4MiB aggregate replies; each reply is at most1MiB and request256KiB. Only four compiled `/v1/research-explore/` routes are permitted. Transport uses a configured authenticated127.0.0.1 origin, explicit port, no proxy/redirect/retry. There is no automatic pagination; returned next_position makes omitted remainder explicit. Share a window to bound multiple page reads. Caller chooses any subsequent page explicitly.

`catalog(selection, window)` supports experiment-bearing queries, validates exact experiment and all three local serialization schema pins, and raises on unavailable/invalid catalog. Series selection has no implied experiment and cannot use this helper. Catalog is capability metadata, never source access or a permission token.

A page read returns either a verified immutable ViewPage or finite technical failure plus call/byte deltas. Unknown programming errors propagate. Failure never becomes an empty successful result; unrelated reads can continue within remaining budget. An expired window or exhausted aggregate budget must be replaced only under a separately authorized operation. No writes, retries, Data source fetch, active-campaign invalidation or repinning occur here.

Tests live in `tests/research_view_access`, registered through dev/test_scopes.json's agent-planning module scope. Public fixture vectors are copied locally for independent installation; scope-adapted tests recompute query identity. Replacement must preserve literal query vectors, scope/identity checks, exact HTTP bodies, explicit pagination, budgets and partial outcomes. Loopback and independent-wheel tests prove client policy only; actual Research owner compatibility is the separate B1.02a.iii gate.
