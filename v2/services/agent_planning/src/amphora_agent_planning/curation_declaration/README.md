# Reviewed declaration publication

UI-01.08/P2.3c.1; migration0025. Architecture: ../../../../../docs/Architecture/Agents/Planning.md.
DeclarationOrigin retains the exact operator policy, original human command and
Runtime readback before publication. It reconstructs compiler declaration bytes;
configuration change cannot rewrite a registered origin. No model capture or
scientific evaluation is fabricated. Origin digest pins all retained source inputs.

DeclarationArtifact is derived configuration using existing Data derived-upload
contracts. Its parents are reviewed objective/policy/model/prompt Artifact roots.
Selected source/graph references are metadata in the retained command; their bodies
are read separately under processing rights. This publisher creates no rights
records and no source-delivery identity. Data owns current parent access and
transitive processing rights. Transformation ID explicitly names reviewed curation
configuration; original command/Runtime/policy evidence stays in Planning.

DeclarationJournal stores immutable origin and <=64 hashed/replayed upload events,
with active curation job fence and expected event-position guards. Transactions
contain no peer/model I/O. Existing PublicationAttempt/drive_upload handle exact
command receipt recovery, once-only PUT transition and bounded replacement of an
uncertain upload (max8 upload attempts; these are not model calls). Immutable final
Artifact and derivation receipt must match all original descriptors and commands.

DeclarationTransport preserves existing closed derived-upload paths, localhost
credentials, five-second wall-clock exchange and byte limits. Only this subclass
also permits text/plain request media for declaration bytes; older publication
transport remains application/json-only. Response JSON checks remain unchanged.
DeclarationPublisher recovers retained origins before consulting new configuration.
No provider call, budget reservation, Runtime graph mutation or source-right grant.
Tests: tests/curation_declaration. Actual owner/managed process qualification remains
later P2 gates; this is an internal publication module, not a new public API.
