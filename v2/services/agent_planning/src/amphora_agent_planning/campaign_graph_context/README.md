# Campaign graph projection

Owner: Agent Planning. Architecture: [Planning](../../../../../docs/Architecture/Agents/Planning.md). Pure selected graph projection; campaign_knowledge_access owns bounded public reads and graph_context owns record validation. No peer implementation, I/O, persistence, current-head lookup or scientific authority.

CampaignGraphProjection rebinds an immutable campaign selection and validated pinned context. It includes selected assertions/entities, exact assertion endpoints and complete relevant alias source/target chains, including actual alias source revisions newer than selected historical revisions. Selected retraction records remain explicit. Unrelated entities/assertions are not added; supersedes/applicability/source references remain references rather than recursive fetches. The profile and original graph/head/vocabulary/policy/selection pins remain visible. Canonical sorted UTF-8 bytes are capped at1MiB with explicit unavailable projection rather than truncation.

Relevant GraphObservations hash the consumed profile, entity/assertion records, and both present and absent alias/retraction state. The whole snapshot digest remains provenance; changes compares only the original relevant observations against another projection in the same scope. Unrelated additions do not invalidate selected context. Missing relevant observations remain changes, not unchanged defaults. This comparison does not rebase or invalidate an active campaign; later proposal policy owns its use for future work. Historical/retracted observations are not editable targets or proven science.

from_result preserves explicit technical read failures with no partial graph. Malformed result shapes and unexpected failures raise. The projector cannot establish that a supplied pure context contacted Knowledge; production preparation must use the bounded reader. Downstream packet assembly owns required/optional inclusion, tokenizer fit, source processing checks, trusted instruction separation and durable preparation. Replacement must preserve selection/digest/observation semantics and dependency closure, including original owner alias records. Tests under tests/campaign_graph_context cover dependency closure, historical aliases/retractions, relevant comparison, genesis, failure and size boundaries.
