# Finite ground reasoning

- Status: BP-06.03/B1 private pure kernel and owner-state binding; public API, artifacts and receipts not implemented.
- Owner: Knowledge; [reasoning architecture](../../../../../docs/Architecture/Knowledge/Reasoning.md), [activation contract](../../../../../docs/Audits/BP-06.03_Activation.md).

`Program`, `Rule`, `Fact` and `Seed` own validated immutable inputs. Rules are finite grounded implications with one or more explicit premises; no variables, arbitrary expressions, imports, subprocesses, callbacks or negation-as-failure are evaluated. Atom strings are private symbols, not trusted graph references. Supplying a program version or seed origin does not confer scientific authority.

`GraphInputs.from_state` consumes an owner-reconstructed GraphState, never a caller-supplied snapshot DTO. It pins the semantic snapshot and exact scoped context artifact, selects all current nonretracted assertions with identical applicability and reports other-context exclusions explicitly. Endpoint reference digests preserve entity revision identity; aliases do not silently substitute endpoints. Seed origins map to exact assertion revisions; unknown origins and stale/retracted references cannot resolve through this binding. Raw represented hypotheses remain hypotheses: logical entailment from them is not scientific support. Public requests will still require authenticated owner reads, configured rule policy and current-rights checks before publication.

`Evaluator.evaluate` computes deterministic monotonic closure in synchronous rounds. Positive and negative facts coexist; both yield unknown with an explicit conflict flag. Missing facts remain unknown. Cycles without seeds derive nothing; seeded cycles terminate without cyclic proof links. Input order cannot change output. One deterministic shallow proof is retained per derived fact, with all direct input origins retained for seeded facts. This is an explanation witness, not enumeration of every possible proof. Original origins remain original evidence; derivation steps cannot be counted as independent observations.

Inputs cap256 rules,16 premises per rule and8192 seeds. Configured budgets cap64 derivation depth,8192 retained facts and1,000,000 rule/premise checks. Default limits are32/8192/100,000. An incomplete round publishes no partial candidates. Productive depth/fact overflow or work exhaustion produces an incomplete closure; assessment remains unknown even when a supporting prefix exists. Invalid inputs fail before evaluation. No database, network, artifact writes or publication occurs here.

Owned tests: `tests/reasoning`; selector `dev/run_tests.py --module knowledge --area reasoning`. Independent oracles cover explicit negation, conflict without explosion, conjunctive premises, seeded/unseeded cycles, bounded failure, deterministic ordering and original-evidence lineage. This pure fixture proof is separate from required public contracts, exact applicability, owner persistence and real peer/Runtime integration. Replacement must retain these semantics and their explicit incompleteness status.
