# Research exploration

Design: [scientific views](../../../../../docs/Build%20Plans/BP-06/BP-06.06%20Research%20views%20design.md). BP-06.06/B1.03a implements pure projections in Research0.32 with public research-views0.1. Owner/HTTP integration is B1.03b.

`ExperimentProjection` owns the exact experiment's specimen inventory and declared expectation lookup. `ObservationProjection` owns reported measurement preview and lossless series windows. Both revalidate immutable wire records, enforce1MiB input limits and reconstruct existing Research domain validators. They do no I/O, persistence, authentication, normalization, matching acceptance or scientific evaluation. Transport DTOs come from the separate public research_views contract package; all existing Research contracts remain unchanged.

`ViewQuery` validates strict query shapes, unique scoped observation selections, complete ordered query SHA-256 and bounded positions. Limits:16 specimen/property rows,128 explicitly selected observation revisions,256 series points,1MiB complete output. Exact revision references and page size belong to query identity; position does not. Typed offsets confer no authority. Immutable experiment order, observation selection order and original series order are preserved, including duplicate x values. Equal nominal candidates never collapse separate samples/prepared states.

Specimen rows retain SampleIdentity plus exact material/candidate/supersedes and preparation/feature counts; missing state stays null. Existing exact material reads own full evidence. Property rows retain original binding/source/quality and unmodified scalar decimal/censor/missing/uncertainty shapes. Series previews contain units and total, with full points available through bounded exact-observation windows. Reported claims can be unbound, refer to another experiment or have an unknown expectation. A declared expectation link is descriptive only; failed controls and mismatches remain visible. No implied timestamps, aggregation or scientific acceptance.

Pure `properties(request, records)` requires exactly that query page's ordered observation records. The future owner adapter must establish existence of the entire bounded selected set before returning any page, authorize current grants/scope, and load only the selected page. Pure success does not claim database existence or current Data rights. Catalog pins three reviewed serialization schemas; descriptors carry no browser routes. `ResearchViewError` codes begin view_; domain reconstruction can also raise the existing scientific module errors.

Tests live in `tests/exploration`, public shape tests in `contracts/research_views/tests`. Replacement preserves exact records/query/order, distinct state identities, original measurement lexical semantics, limits and failure distinctions. Pure tests prove neither persistence nor HTTP/peer availability. Independently installed owner/API and source reads remain separately evidenced gates.
