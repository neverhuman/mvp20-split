evidence.py separates DecisionSubject (exact candidate and optional state/sample) from DecisionContext (domain, purpose, conditions), EvidenceOrigin (immutable source, method, kind, claimed authority and optional observation revision) and CriterionClaim (attributed disposition/quality flags). All owned references have coherent scope. Missing subject metadata is explicit and cannot match a more specific context. A source claim is not authenticated merely because it constructs successfully. Measurement, model and synthesis evidence are distinct kinds.

policy.py binds a versioned policy reference, exact context and nonempty bounded Requirement set. Each requirement explicitly declares its evidence kind/method, whether it is a hard prerequisite and which quality flags exclude its evidence. Claims with incorrect context, authority, kind, method or declared quality remain in ClaimReview with reasons. Undeclared criteria remain inspectable. Duplicate criterion/source/observation identities are rejected; repeated support cannot outvote contradictory evidence. Source order is preserved in the decision.

For each criterion, opposing support/contradiction yields unknown/conflicting_evidence. Any explicit uncertainty among accepted claims keeps the criterion unknown. Otherwise contradiction is failed, support is supported, and absent eligible evidence is unknown. Across required criteria, a definite failure makes the requested action ineligible; otherwise an unknown prerequisite makes it unknown; otherwise eligible. Optional weaknesses never impose a hard gate. A policy with only optional criteria is explicitly exploratory and can remain eligible with missing evidence. No empty policy is fabricated.

EligibilityDecision retains every review, criterion decision, exact source/observation reference and policy/context. Its focus property identifies declared criteria with nonsupporting status, rejected claims or flags for later inspection and iteration. Focus is a small domain projection, not a UI implementation, ranking algorithm or global consumer index. Fixed synthetic authority prevents this profile from accepting claimed scientific authority. No eligibility verdict declares the candidate universally good, scientifically true or fit for another purpose.

These frozen objects have no I/O, storage, source resolution, numeric threshold interpretation, unit normalization, receipt publication, graph mutation or active-campaign correction adoption. Later measurement/model/synthesis adapters must produce properly authenticated and interpreted claims; constructing CriterionClaim cannot replace that work. Policy/source reference integrity and model applicability are later boundary checks. Dependencies are public contracts/Pydantic and private Research observation identity. Replacement tests in tests/eligibility preserve hard versus optional gates, exact context, original evidence, unknown/conflict semantics and future-only reevaluation. Run dev/run_tests.py --module research --area eligibility. Malformed input raises stable EligibilityError; no invalid input is coerced into favorable evidence.

## Immutable decisions and dependency tracking

decision.prepare evaluates the owner policy and derives an EligibilityDecision document containing full configuration, all claim reviews (including rejected/weak points), sources and exact observation revisions. The decision reference digest covers scope/kind/id, actor, full assessment and complete indexed dependencies; it excludes its own reference to avoid self-hashing. Changing a policy, actor, input or decision identity changes the digest. A synthetically eligible exploratory result retains optional weaknesses in focus; storage cannot promote its authority.

EligibilityStore.assess takes private policy/claim objects, not caller-provided output verdicts. It validates the target candidate and optional state/sample against exact immutable owner records, requires known observation revisions with matching source Artifacts, then commits result and dependency indexes together. Unknown context remains explicit; a sample cannot silently drop its known state. Claims rejected by policy still remain indexed. Model/synthesis claims have Artifact dependencies without invented observation identities. No numeric interpretation or source-authentication claim is added: trusted adapters must authenticate/interpret inputs before invoking this private boundary.

Both stores use closed Research-local decision journal mechanics in persistence, with research_0008 append-only grants. Exact retry preserves bytes/original actor; changed input/profile/actor under the same identity conflicts. Read requires exact scope/kind/id/digest and returns committed history without policy rerun. Source count is bounded at128 distinct Artifact identities; conflicting references for one id fail, never silently merge. Canonical output is capped at8MiB. A new decision uses a new identity; corrections cannot rewrite old decisions or campaign fitness.

DecisionIndex exposes bounded pages of dependents by exact observation revision or exact Artifact reference, plus explicitly registered immutable consumer Artifacts. DecisionIndex registration is a private adapter call; scientific_api verifies the consumer through Data publisher proof and exact published-decision lineage before calling it. An ArtifactRef alone confers no trust. It makes no global-consumer discovery or automatic feedback claim. Pages are a live append-only index, not a snapshot: concurrent insertions before a cursor require a fresh scan; later correction orchestration must account for that. Every page preserves future_campaigns_only policy. Rights/security remain separate.

Module-owned tests cover decision provenance, exact replay/replacement, dependency integrity and historical correction isolation. Persistence tests cover shared encoding/page/grant mechanisms. Local postcommit reply-loss probes are not process-kill evidence. Actual API/replacement evidence belongs to scientific_api; actual Artifact publisher process recovery is documented in scientific_publication. Rebuilds must preserve full policy/result bytes, references, dependency pages, actor attribution and immutable consumer links; no active-campaign mutation or implicit scientific promotion is permitted.
