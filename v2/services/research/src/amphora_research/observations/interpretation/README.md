# Observation interpretation boundary

Design status: BP-06.04/B2.03a implemented; persistence and authenticated API are subsequent slices. Research0.27.0/contracts0.12.0. Owner architecture: [experiments](../../../../../../docs/Architecture/Research/Experiments.md).

This private Research module reconstructs reviewed conversion/action-use profiles, binds reference-only requests and computes immutable content-addressed projections. It imports public core/research DTOs and private Research observation/experiment objects. Other services use the public contracts; no private cross-service imports or shared database authority exist.

`profiles.py` owns `InterpretationProfile`: exact scope, one closed policy kind, complete reviewed catalog/action requirements, transitive content hashes and strict request identity. Catalog reconstruction reruns exact-decimal, direction, dimension and resource invariants. Action-use reconstruction verifies its own hash and any nested catalog hash. Requests cannot supply replacement values or verdicts. Use requests preserve order and reject repeated observation identities, including different revisions posing as independent replicates.

`wire.py` maps computed values only. Original lexical values, units, censoring, uncertainty, control claims and quality flags remain visible. Raw and effective matching are distinct; `state_bound` means a referenced state record exists, not that its scientific context is known. `focus` identifies next-campaign attention independently of per-action blockers/gaps. There is no campaign-wide quality verdict, numeric confidence invention or scientific acceptance.

`document.py` computes results from original domain objects after verifying exact requested observation/experiment references. The full profile, original actor, scope, stable interpretation id, original/result content and supplied consumed source list determine the digest. Canonical JSON has an8MiB ceiling; at most128 exact scoped Artifacts are retained, duplicates collapse and conflicting identities fail. No truncation or rounding occurs. Empty use batches retain missing-expectation coverage. Unknown normalization remains a completed unresolved computation, distinct from operational inability to authenticate inputs.

These pure builders do not load/verify owner storage, authenticate Data sources, select current revisions, persist results or expose HTTP. Supplied consumed sources are private preparation inputs, not proof of source rights. B2.03b must enumerate/verify complete dependencies and persist accepted configuration plus atomic result/index/outcome before success; B2.04 must authenticate new-use reads. No Artifact publication, DomainReceipt, Runtime retention, active invalidation or campaign repinning is conferred. Corrections remain future-campaign inputs.

Tests belong in `services/research/tests/observations/interpretation`; `dev/run_tests.py --module research --area observations/interpretation` is the granular entry. Contract examples/schema tests belong in `contracts/research/tests/test_interpretation.py`. Replacement must preserve complete profile hashing, exact reference binding, original evidence, per-action semantics, output bytes and bounded resources. Source and installed-wheel evidence is tracked by the owning plan; UI display remains SQ-01.
