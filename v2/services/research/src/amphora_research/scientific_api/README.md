boundary.py owns ConfiguredScientificInput and BoundScientificAssessment. EligibilityInputProfile and SynthesisInputProfile are reviewed operator configuration, not incoming policy edits. Construction revalidates the public DTO and reconstructs the respective private policy object, preserving explicit action prerequisites, optional weaknesses, unknowns and fixed synthetic authority. Duplicate trusted publishers fail; full configuration is bounded2MiB. A scope/kind/id/version reference hashes the complete configuration, so reusing a label cannot conceal changed adapter, publisher or policy behavior.

Binding revalidates the reference-only ScientificAssessmentRequest, authenticated actor and Scope. Full profile identity must match; every report belongs to the same scope. At most16 immutable report references are allowed; repeated Artifact ids are rejected even if their other fields differ. Report order is preserved for later evidence evaluation. Bound keys use scope/kind/decision identity. No network request, SQL transaction, source trust decision, result verdict or persistent intent is performed by this module yet.

Public contracts are exported from amphora_contracts_research. SyntheticEligibilityReport and SyntheticSynthesisReport have self-contained payload-schema helpers, explicit adapter/issuer/raw-source fields, bounded original evidence and fixed synthetic authority. An eligibility claim's absent source means the actual authenticated report Artifact will be attached by the resolver, avoiding a self-hash. Explicit original evidence sources remain references that must be authorized and lineage-checked. Shape validity is not producer authentication; the resolver remains the next implementation slice.

ScientificAssessmentStatus separates pending from assessed output. ScientificPublicationRequest selects a committed lab intake or exact decision reference; it cannot carry replacement bytes, publisher, actor or a DomainReceipt. ScientificPublicationStatus returns pending, failed operational publication with possible external effects, or Artifact derivation evidence. Impact and consumer requests remain bounded reference selections; no active-campaign invalidation or global discovery authority is added.
