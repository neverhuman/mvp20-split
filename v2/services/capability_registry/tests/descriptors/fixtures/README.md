# Descriptor Failure Oracles

`failure_oracles.json` is hand-authored acceptance data. Each case applies one explicit mutation to the published numeric fixture or changes the requested scientific context. Expected rejection stage, findings and reason codes are specified independently; never regenerate them from implementation output.

Wire cases must fail both Pydantic and JSON Schema. Lock cases compare against the unchanged published lock. Selection cases retain a fresh, exact-release healthy-capacity observation and assert each independent assessment, so operational health cannot hide scientific or policy rejection. Metadata-only fixtures make no scientific-efficacy claim.

`test_failure_oracles.py` owns the runner and additional bounded-constructor, request-completeness, checkpoint and diagnostic-limit cases. Run the registry/descriptors selector; installed package and actual peer compatibility belong to the separate acceptance harness.
