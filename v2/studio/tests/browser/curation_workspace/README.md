# Curation workspace qualification

Production dist/local entry with scripted public owner APIs. The fixture provides
consistent synthetic original launch/provenance and retained planning context,
queued/current curation views, successor receipt and Runtime observations. It does
not call a provider, start a tool, or attest science. No test-only UI callbacks
replace production navigation.

Run build-local.mjs then tests/browser/curation_workspace.mjs from Studio. Checks
cover composer/proposal/successor/Runtime inspection, predecessor selection, later
missing capability and explicit new-request preparation.1440/390 screenshots,
WCAG/overflow, request counts and failures are written to the supplied evidence
directory. Actual owner/process and live-provider tiers remain separate.
