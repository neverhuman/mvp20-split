# Candidate presentation

Results discovers bounded direct structural outputs and opens one candidate at a
time. The same inspector is available on a selected execution activation. Page
models own discovery, owner reads, identity checks and image validation; components
render props and own only local disclosure/selection/image-error state.

The supplied finite molecule displays formula, inert validated 2D PNG, canonical
SMILES, method and retained provenance. It stays unranked with explicit absent
property/synthesis evidence. Unsupported structures show the producing tool's
failure without guessed chemistry. No scalar fixture is assigned a molecule.
Execution disclosure stays on the candidate's exact read cut/activation/attempt;
it never silently follows a newer run or graph revision. Candidate predecessor
revision is shown only when retained by Research; population lineage is POP-01.

Result discovery is limited to two observation pages/100 nodes and direct outputs;
collection or omitted-node coverage is explicitly partial. Hidden results cancel
and clear discovery/inspection. Showing the tab again rereads owners. Browser tests
live under tests/browser/candidate_inspector; P4 separately proves actual owners,
installed Gateway and LAN integration. No browser credentials or external renderer.
