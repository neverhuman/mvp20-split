# Candidate inspector

UI-02/P3 owns a disposable read-only projection of one accepted structural tool
output at one Runtime snapshot. Runtime owns execution acceptance, Data owns current
artifact access and bytes, Research owns candidate identity, and the scientific tool
owns chemical interpretation. This module has no scientific ranking or write authority.

`CandidateExecution` binds the selected settled canonical attempt, worker, activation,
invocation, reviewed capability/release, sole structure input and result output to the
visible read cut. Full image digest is retained from the authenticated Runtime proof;
Studio does not claim independent container verification. `CandidateContents` checks
scope, exact request-byte hash, semantic profile, candidate revision and registered
representation. Basic indexed graph connectivity and charge consistency reject broken
bundles; this is not a second chemistry kernel. Formula/depiction are tool-derived.

`CandidateInspectorModel` uses existing public owner APIs and current Data metadata/
content reads. A RequestLane clears prior output on rebind, denial, hide and disposal;
uncancellable replies cannot repopulate it. Missing canonical attempts on the loaded
attempt page require refresh/attempt inspection, never guessing another attempt.
Supported tool failures remain explicit without invented formula/registration.

`verifiedPNG` accepts bounded, CRC-checked, noninterlaced 8-bit RGB/RGBA PNG with
IHDR, optional bKGD, IDAT and IEND only. It checks the retained digest, dimensions,
exact bounded decompressed scanline length and filters. Only then emits an inert
image data URL. No SVG, animation, external resource, metadata or chemistry runtime.
The browser remains responsible for rendering; actual browser qualification is P4.

All supplied structures remain unranked. Property and synthesis evidence are absent,
not zero/failed; synthetic numerical search does not establish molecular fitness.
Tests: `tests/page_models/candidate_inspector/` includes actual P1 tool output wrapped
in synthetic read cuts plus wrong producer/identity/artifact/image, denial and race
oracles. Replacement must preserve these boundaries and Data's separate byte checks.
