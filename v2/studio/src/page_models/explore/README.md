# Explore page state

BP-06.06/B2.01 implementation boundary. User: an internal researcher inspecting a pinned domain graph and laboratory context. Primary question: what does this selected claim or observation say, and which exact source supports it? Primary actions: bounded search/expansion, scientific view selection and source inspection. There are no scientific mutation commands or active-campaign repinning actions here.

One selected view owns the growing region; a selected object and source use detail on demand. Presentation will reuse Studio typography, spacing, controls and accessible list/inspector patterns. Knowledge owns graph projections; Research owns specimen/property/series semantics; Data owns content access and provenance. The model retains explicit graph/experiment/observation pins and never chooses latest revisions. A declared observation remains a claim even when its reported experimental context mismatches.

The model coordinates independent request lanes and immutable render snapshots. Context change, hiding, disposal and authority/query conflicts cancel outstanding work and clear protected data. Generation checks discard uncancellable late replies. Bounded pages replace previous pages rather than accumulating an unbounded graph. Empty, partial, ready, loading, stale, denied, unavailable and failed states remain distinct; sanitized failure kinds preserve timeout/limit details. Transport validates schema and exact replies; model context checks prevent requests from escaping the selected scope/revisions.

No owner credentials, database, persistent cache, scientific scoring, graph mutation or browser fetch belongs in presentation. Selection and viewport policies are view state, not scientific topology. B2.02 owns visible components and actual browser acceptance; tests here prove state/race behavior only. Replacement must preserve context fencing, bounded region ownership, subscription behavior and race/failure oracles before cutover.

Implemented in Studio0.4: ExploreContext accepts graph-only, laboratory-only or combined same-scope pins; ExploreProjection owns immutable region snapshots; ExploreModel reuses RequestLane for seven independently loaded regions. Property selections preserve exact ordered observations; series reads require a selected observation. A new graph detail clears its previous source. Shape/identity validation remains in the transport, while no newer head is inferred.
