# Inline occurrence scopes

Owns bounded composition for an SME asking which sibling branches are active,
complete, failed or waiting while retaining upstream/downstream campaign context.
Runtime scope/topology reads are the sole source. No writes, snapshot creation,
scientific interpretation, invented tools, worker scheduling or timing inference.

InlineScopes reads at the parent Monitor snapshot token/read cut. At most four
sibling scopes per expansion, eight expanded groups, depth three and 200 rendered
nodes. Partial pages/groups disclose omissions; isolated navigation remains available.
Hidden/changed observations cancel and clear reads; generation fences reject late
responses. Denial or cut mismatch clears every group and invalidates navigation.
Other failures show a retryable group error. Module tests own these boundaries.

The projection preserves owner activation IDs and states. Parallel child roots fan
out together. Finish nodes converge on a synthetic group-completion boundary whose
selection resolves to the parent activation; it is not a newly executed tool.
Iterations connect in ordinal order, distinct from scatter siblings. Solid lines
are original in-scope control links; dashed lines are derived scope-entry/completion
and continuation relations. No cross-scope link is represented as a published edge.
An issued state is not proof of CPU overlap; no timestamps or percentages invented.

Default root scatter expansion shows sibling work without requiring discovery in
an inspector. Other groups expand/collapse explicitly. Viewports belong to the
scope plus expansion selection. Existing narrow topology navigation stays available.
Expansion choices survive hidden views and refresh within the same run/plan;
fresh owner reads are mandatory before restoring child records. Denial and run
replacement clear those choices. A focused expanded-work viewport and pannable
overview map preserve readability; Fit graph exposes the entire loaded projection.
Large all-generation overviews require zoom to read individual tool labels.
