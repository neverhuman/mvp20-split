# Candidate recommendation evidence

Owner: Studio / UI-02 P2. User: researcher inspecting one candidate. Primary question:
what retained policy selected it, or why is it unranked? No mutation commands.
Transport and current artifact rights remain with the existing bounded Data clients;
this module consumes an already decoded RetainedGeneration or validated structure
identity. P3 owns loading/denial/cancellation, exact chemical producer proof and UI.

RetainedSelection snapshots the public numeric SearchCheckpoint selection receipt,
policy, objectives/directions/units, evaluator/constraint/context, generation,
membership pin, selected set, ranks/fronts, qualities and values. It validates
receipt/candidate/feasibility consistency without calculating dominance, fitness,
ranks or a winner. Same-front membership does not mean equal objective values or
one best candidate. A configured numeric policy without a retained selection receipt is selection_unavailable;
missing molecular policy, incomplete stage, zero request, insufficient
feasible evidence and different specifications remain distinct. Missing objectives
are never zero. A numerical genotype remains a numerical genotype.

The existing Research fitness authority is synthetic_owner_projection; it is not
an applicable molecular ranking producer. suppliedStructureEvidence binds exact
candidate/revision and representation scope, returns unranked and explicitly absent
property/synthesis evidence. A numerical selection cannot be attached as molecular
fitness, even if identifiers match. These objects do not attest scientific accuracy,
authenticate artifacts, discover absent data or imply that a molecule was generated.

Tests: tests/page_models/candidate_evidence, alongside generation_comparison tests.
Reuse the existing result/inspector tokens and progressive disclosure in P3: compact
status, objectives/constraints in a comparison table, details on selection. No
independent fetching from presentation or full-population browser ranking. P2 is a
pure evidence projection; no new backend API, schemas or browser delivery claimed.
