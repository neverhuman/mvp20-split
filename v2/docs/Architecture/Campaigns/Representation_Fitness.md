# Candidate representation and fitness boundaries

- Design status: synthetic operators and candidate declaration ingress implemented; representation canonicalization and declared evaluation identity implemented; owner fitness projection implemented; actual peer integration and authoritative reuse remain B2.03.
- Last reviewed: 2026-10-06 14:05:50 (America/Chicago).
- Parent: [Search](Search.md).

Three independently packaged tools own synthetic bounded numeric coordinates, labeled polymer-chain blueprints and DNA strings. They depend on a new public candidate_spaces DTO package, never each other's implementations. Existing contracts/representations continues to own vector-space encodings; existing numerical search/checkpoint contracts remain stable. These fixtures exercise domain separation, not molecular validity or biological function.

Each design binds scope, exact profile and literal synthetic authority. Numeric coordinates retain identifier, unit, bounds and value. Polymer blueprints retain repeat-unit labels, composition, labeled sites/connectivity, explicitly nullable sequence arrangement, tacticity, degree/distribution descriptors, branching and end-group information, plus optional BigSMILES text. A labeled blueprint is not an atom graph, synthesized chain or measured distribution. Material preparation/morphology remains a separate Research material-state identity. DNA fixtures declare their alphabet and sequence; polymer fields cannot appear there.

Operator requests carry an exact source design and a typed proposed move: set one bounded numeric coordinate, replace one declared polymer site label, or substitute one DNA position. The tool validates its own complete source before a move, rejects foreign profiles/operators, preserves scope/profile and immutable source identity, and emits an attributable proposed result. No silent repair, default random/atactic polymer interpretation or chemical inference is permitted. Runtime alone accepts tool completion; Research alone declares candidate revisions. A representation profile digest is not scientific authority.

Canonicalization is profile-owned. Numeric coordinate order and DNA order remain meaningful. Polymer canonicalization may sort unordered declaration/site/edge lists under an explicit versioned policy, but cannot infer chemical graph isomorphism, collapse unknown into specified values or ignore distribution/end-group fields. Every attempt remains attributable even when its declared canonical identity matches an earlier one.

A reusable evaluation identity binds canonical representation and equivalence revision, purpose, ordered objective names/units/directions, exact evaluator/method, applicability policy, synthesis policy and relevant material-state/context revisions. Equality is necessary for reuse, not authorization: Research/Data must still resolve immutable source decisions and current access. A matching string or vector is insufficient. No implicit unit conversion or comparison across evaluator versions is allowed.

Research owns fitness assembly from authenticated/pinned evidence and eligibility/synthesis decisions. Required hard failures exclude before numeric ranking. Missing, censored or contradictory values remain explicit unavailable outcomes; they never become zero or best rank. Unknown synthesis remains unknown and follows the pinned exploratory versus required-action policy. Optional weakness creates follow-up focus rather than an in-campaign veto. Existing future-campaign-only correction policy remains unchanged.

Test ownership follows each tool and Research fitness module. POL-01 preserves unknown/specified metadata; POL-02 rejects domain-illegal moves; POL-03 blocks cache reuse across context/distribution changes; POL-04 permits declared syntactic equivalence only under identical full evaluation context. Actual public Artifact/Research/Runtime and independent replacement evidence remain required integration gates. No new SQL state is justified until an owner persistence requirement is identified.

## Declared evaluation identity

B2.01b introduces public evaluation_identity transport and a focused Research fitness/reuse policy object. Representation claims bind scope, source Artifact, canonical digest and exact semantic/equivalence policy. Reviewed evaluation policy binds that representation policy, purpose, ordered objective IDs/units/directions/uncertainty policies, evaluator release/image, method/applicability/synthesis policies, required named context and explicit material-state requirement. Context supplies exact named Artifacts and an optional state revision. Missing required inputs reject rather than becoming a reusable unknown default.

Research validates metadata coherence and produces an identity_only fingerprint of the complete normalized declaration. Named contexts and requirement sets normalize by name; objective order remains significant. Original representation Artifact identity is retained in provenance but excluded from the equivalence key, allowing two explicitly canonical-equivalent encodings to match. Scope, semantic/equivalence policy, canonical representation and every evaluation/context pin remain in the key. No values, source access, canonicalization proof or scientific verdict are supplied by a matching key. B2.03 must resolve reviewed owner/producer evidence and current rights before actual evaluation reuse; this pure object cannot authorize a cache hit.

## Fitness assembly and comparison

A Research-owned synthetic consensus policy composes existing immutable observation-use, action-eligibility and synthesis decisions. It binds the full evaluation policy, observation-use policy and explicit synthesis requirement under a content-derived policy reference. Objective IDs select sample-role experiment readouts for the exact candidate/material state. Every matching expectation must have usable numeric evidence with the declared unit. Censored, missing, excluded, quarantined and differing replicate values remain unavailable; no implicit averaging, zero substitution or unit conversion is introduced. Original reviews, normalized measurements and uncertainty intervals remain attributable.

Required eligibility failure excludes before ranking; unknown prerequisites remain unavailable. Synthesis decisions retain all alternatives and their unknown state; only an explicitly required synthesis action gates fitness. Optional gaps become next-campaign focus. Ready vectors compare exact decimal central values under the same policy and named context, respecting objective direction. Such Pareto comparison is an explicitly synthetic central-value policy, not statistical confidence or scientific superiority. Material states and candidate identities can differ when comparison context agrees; reuse identity continues to require the exact state.

Pure assembly validates internal coherence but does not authenticate records. The service boundary must resolve exact committed owner records and current source rights, persist the result before returning success, and retain original history across replacement. Matching declared evaluation keys never replace those checks.

Fitness projection implementation uses a reference-only request, current bounded public Data reads outside SQL, exact committed owner resolution and append-only research_0015. Full provenance and synthetic_owner_projection/reuse_authority=none remain explicit. Independent actual peers and producer-backed reuse are a separate gate from these owner SQL/API checks.

## Producer-backed synthetic reuse

A canonicalization capability belongs to each representation tool and accepts that tool's direct design schema. Its receipt binds the exact input-byte SHA-256, scope, representation kind, semantic/equivalence profiles and canonical digest. It is synthetic encoding evidence, not scientific equivalence or permission. The original input Artifact is recovered from the accepted Runtime invocation; the receipt cannot supply its own trusted origin.

Research authenticates a capability result through Runtime?s accepted-producer projection, which binds the original invocation specification (exact tool binding and inputs), settled attempt and canonical successful completion in one read-only owner transaction. Existing separate claim/completion inspection remains useful, but workers do not expose their random claim command IDs. A completion without the matching invocation is insufficient. Current Data reads independently bind the actual payload bytes. No Research import of tool implementation or cross-owner SQL is allowed.

Initial reuse qualification is limited to an explicitly synthetic deterministic evaluation. Both source and target canonicalization, the source evaluation producer, complete versioned evaluation context, current Artifact rights and target Research action eligibility must agree before an immutable reuse decision returns the original evaluation Artifact. The decision preserves original producer/candidate provenance; it does not recast measured observations as measurements on a new specimen. Existing fitness projections remain reuse_authority=none. Real scientific equivalence/evaluators require their own reviewed applicability and evidence rather than inheriting synthetic test qualification.

### Synthetic evaluation oracle

The initial independently packaged digest evaluator accepts EvaluationIdentityInput, checks its own exact image/release binding and method/applicability/uncertainty profiles, and returns the unsigned integer represented by the first six hexadecimal digits of the declared canonical digest (0..16777215). Its only objective is synthetic-digest-score, unit1, minimize, purpose synthetic-cache-qualification. The output retains scope, exact input-byte hash, canonical digest and full evaluation-method pins. This is an engineering oracle, not measured fitness, a hash-based scientific model or canonicalization authority. Research must authenticate the actual Runtime producer, read its exact Data input/output, and check both representation-tool proofs before reuse. Context and eligibility still govern reuse even though this synthetic score ignores those contextual inputs. This deliberately exercises rejection of equal-valued evaluations with incompatible contexts.
