The active Research architecture describes candidate structures generally but its
implemented ingress explicitly states synthetic-only. P1 therefore needs a versioned
chemical representation and a material admission-profile decision, not a UI-only
illustration attached to existing numeric fixtures. UI-02.01 spells out fields,
bounds, ownership, failure semantics, compatibility, initial supplied finite-molecule
scope and independent acceptance before publication.

No private cross-owner access, new Runtime graph behavior, retroactive candidate
replacement, paid model request or depiction-as-scientific-truth is needed. Current
demo remains available. Formula for a finite chain cannot stand in for an unknown
polymer repeat/distribution; unsupported forms remain explicit. This restriction
and the alternative wider first profile are visible for owner review.

Progress basis remains four equal UI-02 phases. P1 is decomposed into four ordered
implementation gates without adding parent weight. Parent/MBT/Restore/index are
synchronized; owner direction blocks only chemical-profile publication/dependent
implementation, not this completed design/inventory work.
