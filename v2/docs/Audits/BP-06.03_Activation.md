## Semantic defaults and limits

Use finite grounded Horn-style implications over explicitly signed atoms as the initial synthetic kernel. Both polarities remain visible; contradiction never entails unrelated facts. Cycles terminate by monotonic set growth; no seed means no conclusion. A productive step beyond configured depth or exhausted work/fact budget is an incomplete result, never silently complete support. Stable ordering makes the bounded result independent of request ordering. Derived assertions retain their premises and are never counted as independent observations.

Applicability is exact pinned context for the first fixture profile; no unstated subsumption or cross-context generalization. Opinion, simulation, observation and independent replication remain categories governed by explicit policy, not a numeric hierarchy. Independence cannot be inferred merely from distinct artifact IDs. Absence and conflicting evidence cause abstention/gaps under the fixture policy. These engineering defaults do not select or validate scientific rules.

## Ownership and verification gates

Knowledge tests live in services/knowledge/tests/reasoning; Research tests in services/research/tests/eligibility. Runtime wait regressions remain Runtime-owned. Contracts have package-owned fixtures. Register granular areas before use. Pure rule tests cover chains, unseeded/seeded cycles, contradictions without explosion, order invariance and all bounds. Snapshot adapters cover stale/retracted/foreign references and exact applicability. Persistence tests cover collisions, rollback, concurrent duplicate requests and retained immutable history. Real processes verify public Data/Knowledge/Research/Runtime paths; synthetic inputs remain labeled.

No new service, shared ORM or peer-private import is authorized by this design. Existing exact receipt pins and owner grants remain authoritative. Invalidating a receipt appends history and identifies consumers; it cannot rewrite a closed runtime wait. Real scientific policy, laboratory material-state eligibility, retrieval, text extraction and target-host deployment remain their named later gates. No user decision currently blocks the synthetic engineering scope.

## Public contract dependency constraint

Knowledge contracts already depend on Research question/need contracts. Research assessment contracts must not import the Knowledge package back. Bind candidate assertion revisions through a typed immutable Knowledge assessment artifact (its canonical content names the exact snapshot/assertion refs); Research service can consume the public Knowledge contract while its own wire DTO carries the artifact pin. Reconcile this mapping before publishing assessment schemas. An artifact hash binds the full assertion set; a free-text summary or an unverified client-provided receipt is not sufficient.
