## Resolved integration drift

- Admission previously required capacity that idle slots had not advertised.
  AdmissionCapacity now offers standby only, waits for acknowledged fresh Registry
  capacity and withdraws it before rebinding; Runtime eligibility remains authoritative.
- Legacy run reads rejected authored graphs. RuntimePeer now consumes the existing
  public graph-observation snapshot, verifies scope/run/plan and projects only lifecycle
  metadata. No legacy endpoint weakening or public wire change.
- Explicit identical launch replay can request recovery of a known accepted run.
  Original receipt equality and public identity checks precede resumption; mismatches
  stay latched. No admission or worker start occurs inside that recovery step.
- The helper drained Gateway/TLS before quiescing standby workers. Its shared shutdown
  sequence now respects worker -> TLS -> Gateway/owners ordering; actual clean drain passes.
- Studio hid incomplete observations but stopped polling after a Runtime409/410.
  It now requests a fresh snapshot on the visible execution view. Denied/invalid
  responses remain hidden and do not enable this retry path.
