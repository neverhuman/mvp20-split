Runtime is the only owner of revision heads, validation/material retention, admission, run authority and command acceptance. Save commits no execution mutation; validation is structural and content/universe pinned. Admission rechecks current head/universe, fresh exact Registry observations, budget and the single-active-campaign guard. Network reads precede the short transaction; eligibility observations and run/publication/receipt commit together. Published material supports existing executions without widening configured admission authority. Registry candidates are bounded observations, not reservations or atomic distributed revocation.

Studio models own behavior and local context; DTOs validate public boundaries. Components consume models instead of fetching independently. Tools/forms use reviewed public descriptor/schema pins. Explicit rebase preserves local content and clears validation; it never merges or activates silently. Pending recovery uses the immutable original submission. A POST409 identity collision cannot adopt an older receipt. Denial fences late replies and preserves local work while clearing protected projections. Focus returns to command status without stealing focus from edits made during the request.

Emergency termination is separate from draft editing. Tests prove both orderings: cancellation first rejects the later completion with run_not_running; completion first preserves canonical result and rejects the captured stop with run_revision_conflict. A later deliberate stop preserves that result. Uploaded output alone is not accepted research evidence, and the UI explicitly retains uncertainty about external effects.
