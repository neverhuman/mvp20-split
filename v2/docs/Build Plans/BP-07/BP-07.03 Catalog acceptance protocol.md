No source processing grant or execution admission follows from catalog discovery.

If a declared budget fails, retain that result and diagnose the implementation or fixture. Do not quietly enlarge budgets or count an incomplete scan as complete. Keep scientific/live-provider and target-host qualification separate from this deterministic gate.
