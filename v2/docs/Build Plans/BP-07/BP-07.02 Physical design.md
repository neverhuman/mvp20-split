## B1.01 initial shape

An immutable task binds scope, source revisions and conversion trace identities, exact base graph head (or genesis), vocabulary and structural policy, the target operation schema and reviewed applicability/context Artifacts. Provider attempt provenance pins prompt/model/configuration through the existing immutable request. Candidate entities use local keys plus explicit existing-identity candidates; ambiguous matches remain unresolved. Candidate assertions preserve subject/object keys, predicate, negation, reported/hypothesis/unresolved posture, source-stated versus inferred origin and exact quotations. No inferred species, dose, method, units or missing fields silently become facts.

Source quotations use the existing half-open byte SourceSpan and exact quote bytes. Raw UTF-8 is the first bounded input profile; unsupported source formats require Data-owned conversion with explicit origin mapping, not character offsets presented as raw byte spans. Pure grounding checks prove identity/digest/bounds and quotation equality; they do not prove current rights, entailment or semantic correctness. Actual rights/source retrieval is B1.04.

Reviewed prompt rendering separates trusted instructions/vocabulary/schema from quoted source data. It requires typed output, exact citations, explicit ambiguity, retained contradictions and no instructions followed from source content. Prompt/schema identities are reproducible configuration; a template is not evidence of model reliability. Research questions, answers and evidence needs retain distinct proposal shapes and provenance. Confidence is qualitative inferred metadata, never an acceptance decision.

Failed and repaired attempts both survive. Planning persists its own trace before claiming success; Data publication is an idempotent external effect with explicit derived-input provenance and current-rights checks. Accepted Knowledge changes link the published trace Artifact through the existing public field.

## Policy, repair and evaluation

Citation geometry cannot decide whether correlation entails causation or an identity is a synonym. Structural validation and reviewed synthetic expected meanings are separate oracles. Ambiguous identity or unsupported certainty remains unresolved/abstained or a bounded clarification proposal; do not add routine human waits. Scope/action/model/egress ceilings remain fixed. Repair is explicitly chained and charged across requests rather than obtaining a fresh unconstrained budget; its physical design must state aggregate admission before activating B2.02.

The reviewed corpus separates calibration and held-out cases with independent expected propositions, permitted alternatives and hard rejections. Cover negation, species/dose/method context, correlation versus causation, alias collision, contradiction, retraction and hostile embedded instructions. Report per-category fixture precision/recall/abstention and zero unauthorized accepted changes/fabricated accepted citations. This does not validate a real model; live thresholds are fixed before BP-07.05 evaluation.

Keep module READMEs sufficient for replacement and update schema/package inventories at verified checkpoints. No synthetic placeholder substitutes for required real-owner integration.

## B1.03 trace persistence and corpus (2026-10-04 03:57:59)

Three equal substeps within existing B1.03 weight: a public trace/immutable derivation domain, b own PostgreSQL task/trace journal, c reviewed synthetic calibration/held-out corpus and installed trace proof. All start0%; no new delivery weight. Trace authority is interpretation_only. Model-claimed source attribution differs explicitly from model inference and missing fields; none becomes a scientific fact because citation bytes match.

An ExtractionTrace binds the registered task digest, exact observed ProviderAttemptRef, prompt/model/policy and source/target-operation schema provenance, transform steps, canonical observation/candidate-output digests, diagnostics and optional prior trace. Trace projection reads persisted request/task/observation facts, not caller-supplied provenance or accounting. Raw output stays in the existing attempt journal. Both successful and failed observations produce immutable traces; pending attempts do not. A repair pointer is lineage only, not dispatch permission or a fresh budget.

Forward planning_0006 introduces own extraction_tasks (one immutable task per engagement) and extraction_traces (one immutable trace per observed physical attempt). Exact retries preserve bytes/hash/timestamp; ID/content/actor/request conflicts reject. Trace parent must already exist with exact digest, same source/target binding and a bounded acyclic depth. No peer calls occur under SQL locks. Data-owned derived publication and current source-rights checks remain B1.04; Knowledge accepted-change linkage uses existing interpretation_artifacts.

The corpus is agent-reviewed synthetic software evidence, not expert scientific gold labels. Calibration and held-out source identities are disjoint; hand-authored expected meanings, permitted alternatives and hard-rejection rules remain distinct from adapter outputs. Categories include negation, applicability, correlation/causation, ambiguous aliases, contradiction, retraction, missing context, opinion-backed answers and embedded instructions. A passage requesting a retraction without an exact accepted assertion identity must stay unresolved. B2.01 must explicitly resolve any additional typed edit/task profile needed for authorized corrections/retractions; do not reinterpret a diagnostic string as a GraphOperation or silently change the published draft-v1 schema.
