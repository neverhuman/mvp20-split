## Contracts and authority

AJV validates requests and responses without coercion/default mutation/property removal; TypeScript declarations are derivatives, not schema authority. Owner catalogs advertise reviewed view/schema identities, never executable routes.

Focused Knowledge and Research clients own fixed routes under separate same-origin gateway prefixes. Browser requests use session credentials only; backend service tokens remain server-side. No deployment gateway is implied by a client adapter. Existing Runtime clients/catalog remain unchanged. Strict caller inputs, exact response query/ref binding and scoped authoritative record checks precede exposure to page models. Research's untrusted reported binding may itself name mismatched/foreign context; preserve that claim as evidence without following it or treating it as authorized owner data.

Normalize only documented omitted query defaults before hashing/sending. Fingerprints reproduce the owner's canonical v1 descriptor with every query field except position; response and continuation digests must match. Different query order/revision/page size cannot reuse positions. Catalog and selected-detail replies must match exact requested identities. No implicit newest-head retry. Query conflict is a distinct sanitized state, not scientific rejection.

## Bounded transport

Requests use POST JSON, at most256KiB; reads return at most1MiB, verified as streamed UTF-8 JSON and strict schema shapes. Same-origin prefixes are reviewed configuration, never source-provided URLs. Redirects fail. Caller abort and timeout cover streaming/validation; late responses after cancellation cannot escape into a newer request lane. Errors expose a small named state vocabulary, never backend bodies or credentials. Transport does not own rendering, scientific rules, caching or campaign intervention.

## Provenance follow-up B1.04b

Data's exact acquisition source/trace reads and artifact metadata/content routes supply provenance. Verify the complete expected reference, scope, artifact size and SHA-256 before displaying source text. Current Data access remains independent from historical graph/Research metadata. The existing owner has full-content reads; an initial inspected document is bounded to4MiB, and the selected span to64KiB. Hash the bounded full content, then slice exact byte offsets and decode UTF-8 fatally. Unsupported/oversized/binary source content remains an explicit unavailable inspector, not fabricated text or silent truncation. Never fetch source-provided URLs or execute source markup/instructions.
