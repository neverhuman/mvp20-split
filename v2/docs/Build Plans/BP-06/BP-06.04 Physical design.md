## Private behavior and module boundaries

| Module | Owns | Does not own |
|---|---|---|
| observations | Exact measurement forms, report identity/reconciliation, immutable result revisions and source attribution | Statistical truth, peer bytes or campaign mutation |
| material_state | Candidate-bound ordered preparation, observed/proposed posture, measured/inferred/unknown morphology and distributions | Chemical equivalence from nominal structure alone |
| experiments | Pinned method/protocol, sample/state expectations, controls/replicates and partial-return completeness | Physical submission or external lab authority |
| synthesis | Candidate/route/domain/context-bound evidence posture and independent project-executability reasons | Route discovery or universal accessibility score |
| eligibility | Versioned applicability/quality requirements, exact consumed references, explicit eligible/ineligible/unknown decisions and correction impact | Fitness mutation, Knowledge promotion or model replacement |

Private value objects own parsing, bounds, missingness and comparison rules; aggregates/policies own identity/context transitions. Public Pydantic records serialize these objects through explicit mappings. No wide DTO constructor substitutes for domain behavior. Each new module gets a source-adjacent README and module-owned tests; public contracts remain in the Research contract package with additive versioned schemas/examples.

## Measurement representation

Preserve numeric values as bounded exact decimal text, never implicit binary-float parsing. Keep original lexical value/unit. Numeric, categorical, censored, missing and bounded series are distinct variants. Reported uncertainty is an explicitly described range with units; absent uncertainty remains unknown, never zero or a confidence percentage. A censored limit is not a point estimate. Series retain source order, duplicate coordinates and explicit missing/censored points; no sorting, imputation or averaging occurs on ingest.

The initial computational bounds are128 characters per decimal,64 significant digits and decimal exponent magnitude128; series at most4096 points. These are resource/representation bounds, not scientific validity criteria. Unsupported inputs retain raw source and an explicit reconciliation failure rather than truncated values. B1.01 introduces pure values only, with no schema/API/storage claim.

Unit normalization occurs only under an exact reviewed conversion-policy reference. A small fixture catalog will demonstrate compatible mass/time conversions and dimension mismatch. Preserve original and normalized values plus transform identity; unknown units stay unresolved. No dimensional inference from a unit string, automatic censor-to-point conversion, outlier removal or general scientific unit ontology is implemented.

## Identity and context

MaterialState binds an exact candidate revision, ordered processing events with method/conditions/units/duration/atmosphere/actor/equipment/source, and explicitly measured/inferred/unknown morphology/distribution evidence. Proposed preparation cannot silently become observed. Missing state or method metadata remains unknown.

ExperimentRequest pins exact sample/candidate/state references, method/context and expected measurement/replicate/control identities. ObservationRevision binds the tested sample/state, raw report, original value/units/uncertainty and reported quality/control status. Unknown or conflicting sample identity is quarantined from eligibility while retaining source evidence; it cannot silently create a sample or borrow another state. Partial batches preserve observed returns and enumerate missing expectations. Contradictory replicates remain separate records, not a majority vote.

## Storage, acquisition and corrections

Use Research-owned immutable revision/decision records with explicit actor/scope and exact predecessor/head checks. Source-result idempotency and revision correction are separate identities. Forward migrations provide bounded canonical bytes, unique scoped identities and append-only history; service writes never access Data/Knowledge/Runtime tables. Complete validation and peer I/O before short owner transactions; no locks span network calls.

An explicitly configured synthetic report adapter consumes immutable Data references through authenticated metadata/content/derivation reads, with exact hash/schema/origin/current-rights checks. Source metadata is not scientific acceptance. Invalid, unmatched and partially mapped returns retain explicit reasons. Decisions persist their exact sample/state/observation/policy/context references before success. Replays return committed history without selecting a newer favorable result.

Corrections create new result/state/decision revisions and expose exact impacted owned eligibility decisions and explicitly recorded immutable consumer references (including fitness artifacts where registered). They never mutate historical consumers or current campaign pins. BP-06.06 owns public feedback dispatch; a later campaign explicitly selects corrected revisions. No global consumer-discovery claim is made.

## Synthesis and candidate eligibility

A route assessment names the exact candidate, domain, route version, method/tool/source versions, requested scale/purity/context and constraint policy. Preserve alternatives and per-step evidence/gaps. Evidence posture distinguishes unassessed, proposed, precedent-supported, demonstrated within scope and bounded no-route search. Execution disposition independently distinguishes eligible, blocked and unknown. A demonstrated route can be project-blocked; absent equipment/precursor/yield evidence stays unknown; no route found is not impossibility or a numeric penalty.

Eligibility consumes exact measurement/model/route evidence under a named purpose and policy. Failed explicit prerequisites yield ineligible; missing required evidence yields unknown; otherwise eligible for that bounded purpose. These states do not declare scientific truth or globally stop useful exploration. Ordinary graph branches enforce their declared hard prerequisites; exploratory alternatives remain possible. Synthetic policy authority remains explicit. Do not repurpose the existing fixed synthetic-sufficiency receipt to assert an unimplemented new authority; public feedback integration is reviewed under.06.

## B1.06 report resolution boundary

The first report profile is explicitly synthetic. SyntheticLabReport names issuer, exact adapter, original raw-report Artifact and at most64 reported observations; the payload omits its own source Artifact to avoid a circular content hash. The resolver attaches the actually verified Data Artifact. An8MiB report-byte ceiling is separate from each stored observation's1MiB bound; neither limit permits truncation. Reviewed LabReturnProfile pins an exact stored experiment, adapter and publishers.

Resolve the owner experiment first, release the owner read transaction, then use scoped bounded authenticated Data metadata/content/derivation reads. Verify schema/hash/current rights, actual publisher/declared issuer, transformation descriptor, raw report and protocol/applicability lineage; read the exact required inputs. Protocol failures, denial and outage remain distinct from negative findings. One fresh reader belongs to each attempt; no cross-request authorization cache.

Reconciliation retains every valid reported observation and exact mismatch reasons. Missing expectation coverage, unavailable measurement values and quality/control status remain separate. A complete return coverage disposition does not imply scientific acceptance; matched weak results can remain useful for exploration. Contradictory or duplicate-return values are not averaged. Duplicate observation identities within a report are rejected. B1.06 proves authenticated resolution only. B1.07 owns atomic durable intake/observation/reconciliation decisions and recorded impacts; B1.08 owns separately granted public intake/read APIs. No existing synthetic-sufficiency receipt is repurposed.

B1.07 details: [durable scientific decisions](BP-06.04%20Durable%20science%20design.md) bounds atomic intake, owned decision/consumer impact records and Artifact-only publication without new Runtime receipt authority.
