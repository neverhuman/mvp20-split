## Exact reviewed normalization

A private conversion catalog has a named id/version and bounded explicit directed rules: source unit, target unit, declared dimension and positive exact decimal scale. Hash its complete content into a method reference. No global unit ontology, string-based dimensional inference, transitive path search or automatic inverse rule. Each unit has one declared dimension; ambiguous duplicate directions and conflicting dimensions fail configuration. A small synthetic fixture catalog demonstrates mass and time. No default production catalog is installed.

The initial rule family is positive multiplicative scaling only. Affine temperature transforms, context-dependent chemistry conversions, arbitrary rational/rounded conversions and scientific calibration require a separately reviewed profile; they are not inferred from this fixture. Compute coefficient/exponent products with exact integer arithmetic, independent of ambient Decimal precision. Preserve original lexical values; derived values may use a canonical exact spelling without asserting measured precision. If the result cannot fit existing decimal representation bounds, retain the original and return unresolved rather than truncate, round or overflow.

A target selection names the value unit and optionally a series coordinate unit. Untargeted coordinates stay exactly original. Numeric points and reported uncertainty ranges scale together; censored inclusivity and bound direction remain unchanged under positive scaling. Censored values never become points. Series keep order, duplicate coordinates and missing points. Standalone missing/category values remain explicitly unresolved for numeric normalization. Normalization is all-or-none for one measurement value; no partially transformed object is presented as complete. Output retains original value, exact profile/target, normalized value when available and applied rules or an unresolved reason. The original observation revision is never replaced by this projection.

## Quality and correction constraints

Completeness, identity matching, available measurement and scientific quality remain separate. A reviewed action may require particular controls or exclude stated flags; exploratory actions can still use qualified evidence when their own prerequisites allow. Contradictory replicates remain individually attributed, with no implicit averaging, majority vote or scientific threshold. Exact specimen/material-state/preparation/context applies before comparison; normalized units cannot establish material equivalence or cache interchangeability.

Corrections append explicit immediate successors through existing immutable owner revisions. Preserve corrected and original sources, identify exact impacted owned decisions and explicitly registered consumers through existing bounded indexes, and target only future campaigns. No active pins, committed decisions, fitness or current scientific interpretation is rewritten. New normalization/quality projections must carry exact inputs and reviewed policy identity; persistence must commit before an authoritative result is exposed. Public routes accept references and reviewed profile selections, never replacement verdicts. Source rights remain a separate authority for new consumption; history reads do not confer new source rights.
