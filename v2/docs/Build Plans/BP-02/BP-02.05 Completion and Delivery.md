1. Register canonical semantic command, then create/reuse an immutable PREPARED intent under run/attempt locks. Bind exact output/checkpoint references and semantic digest. Reusing identity with changed bindings conflicts.
2. Release transaction, obtain artifact protective reservations through its authenticated API, and verify issuer/binding. Persist resumable progress without trusting caller-supplied proof.
3. Reenter lock order and recheck running status, worker policy, current fence/lease, activation/checkpoint revision, budget, intent and reservation bindings. Independent activations use local preconditions; unrelated global run revision advancement is not automatic rejection.
4. Commit accepted result, checkpoint revision, attempt/budget settlement, intent COMMITTED, command receipt, run revision and audit/outbox atomically. On permanent rejection commit ABORTED intent/rejection disposition under the same authority locks; cancellation cannot race a second acceptance.
5. Deliver retention confirmations outside transaction. Outcome lookup exposes immutable committed/aborted intent proof with exact scope/semantic binding; unknown is distinct from aborted.
