## Node evidence and publishable metrics

Refines parent N2.4 evidence inspection and V1 reporting. Keep three distinct groups:

| Group | Publishable content | Required limits |
|---|---|---|
| Execution | Accepted completion counts, failures/retries, duration and measured cost where recorded | Exact run/window, tool version, denominator and outcome definitions; retain every trial, cancellations separate; missing telemetry is unknown |
| Software verification | Known-answer/reference agreement and contract validation results | Named suite/version and sample count; test pass rate is not scientific accuracy |
| Scientific performance | Measured error for numeric predictions or task-appropriate classification metrics | Versioned held-out benchmark, ground truth/protocol, sample size, applicability, uncertainty and leakage controls |

LLM self-reported confidence, a RED score, and execution success are not accuracy
percentages. A node without a relevant benchmark shows **Not scientifically
benchmarked**. Knowledge assertions show evidence/conflict/applicability posture,
not a made-up accuracy badge. Formula validity establishes internal consistency,
not synthesis feasibility or experimentally verified polymer behavior.
