## Objective and Boundaries

Provide a meaningful first Knowledge graph that a user can open and explore. Start with a coherent polymer screening slice: polymer/material concepts, relevant properties, evaluation methods, descriptor/model families, applicability limits, supporting evidence and visible capability gaps.

Planning target: approximately 20–40 concepts and 40–80 meaningful relationships/claims across 5–10 useful source documents or evidence records. K1 sets the exact inventory based on source quality; these counts are a sizing target, not a substitute for useful content or an arbitrary acceptance quota.

Use selected reviewed v1 records as provenance where applicable. Inventory and adapt them into v2; never edit/build/run automation in v1. Preserve superseding corrections and distinguish measured, simulated, predicted, historical and illustrative information. User-supplied ocular documents may be inventoried as possible context without changing their original files or treating them as validated evidence.

This plan does not recover/retrain model weights, fulfill ML-01, import the entire historical corpus, add automated LLM extraction, create new scientific validators or claim biological/clinical efficacy. Model/method entries may describe historical or unavailable capabilities honestly; only current public Registry/Research evidence establishes availability. Broader source/domain qualification remains separate successor work.
