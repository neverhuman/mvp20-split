# Amphora Architecture

## Active Architecture Direction

The canonical current direction is [`Graph-Native Research Engine`](docs/Architecture/Graph_Native_Research_Engine.md).

Amphora has two first-class authored graph types:

- executable campaign graphs define module composition, branching, iteration, retained state, and evolvable research pathways
- neuro-symbolic domain graphs define knowledge, mechanisms, evidence, uncertainty, and the reasoning boundaries of a scientific domain

Execution and provenance lineage is a derived graph projection. Deep human visualization, editing, intervention, and cross-graph traversal are core engine capabilities.

The broader architecture document set is indexed by [`docs/Architecture/README.md`](docs/Architecture/README.md). The preserved operational handoff remains [`HANDOFF.md`](HANDOFF.md).
